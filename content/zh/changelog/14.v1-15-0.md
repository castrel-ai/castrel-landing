## 新功能：持续循环与目标实现模式

过去 Agent 多是「问一句、答一句」的一次性协作，本次发版让它能够长期值守：`/loop` 让 Agent 按节奏持续循环执行，`/goal` 让 Agent 朝着你设定的目标自主推进，直到达成才收尾。两者都在对话输入框输入斜杠即可发起，无需切换工具或编写脚本。

`/loop` 把任意指令或提示变成定时重复任务，例如 `/loop 5m /health payment-service` 每 5 分钟巡检一次支付服务。任务会先立即执行一次，随后按设定的时间间隔重复，7 天后自动停止，也可随时手动取消，适合持续盯守部署状态、告警或任何需要周期性确认的场景，让 Agent 替你保持在线。

`/goal` 为当前对话设定一个完成条件，例如「排查所有 503 错误」。设定后 Agent 会立即着手，并在每一步后不断评估进展，条件满足就自动结束对话，无需手动收尾；输入 `/goal clear` 可随时清除目标。相比一次性提问，`/goal` 让 Agent 围绕结果自主迭代，把「盯着它做完」交给 Agent 自己。

本次同时新增 `/deploy`、`/health` 两个运维斜杠指令，分别基于应用的部署文档发起上线、基于 SLO 文档生成健康报告，详见下方完整发版清单。

## 增强 1 项插件

- **增强**：Zabbix 插件（新增主机组发现、主机搜索，并支持工具调用过程可视化）。

## 完整发版清单

### feat
- 新增 `/loop` 定时重复指令，把任意指令变成按间隔自动循环的值守任务。
- 新增 `/goal` 目标驱动指令，为对话设定完成条件并自动盯守至达成。
- 新增 `/deploy` 指令，依据应用部署文档发起上线并回传部署链接与流水线信息。
- 新增 `/health` 指令，依据应用 SLO 文档生成结构化健康报告。
- 分享的会话链接无需登录即可打开查看。
- 优化工具调用流程，调用过程的可视化展示更准确稳定。
- Zabbix 插件新增主机组发现、主机搜索与工具调用可视化。

### bugfix
- 修复回答 Agent 追问后再次查询数据时，连接器报错无法使用的问题。
