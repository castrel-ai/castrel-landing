## 新功能：Chat 对话体验全面升级

Chat 页面迎来覆盖最广的一次交互重塑，涉及消息阅读区、任务过程折叠、工具调用呈现、会话信息卡片、右侧详情面板、侧边栏和输入框七个维度。

消息阅读区收窄，提升长对话信息密度。Agent 执行步骤默认折叠，每轮只展示一行摘要（步数 + 耗时）。工具调用改为更轻量的显示样式，点击后在右侧详情面板查看具体内容，同一工具的多次调用自动合并计数。新增右侧会话信息卡片，集中展示来源、子智能体、产出物和待办，并根据屏幕宽度自适应显示。

输入框新增 `/` 快捷键切换 Chat 模式，取代原有的按钮下拉选择方式。历史会话进入时自动聚焦最后一个产出物，文档和知识 Tab 展示实际文档名称，侧边栏子 Agent 对话额外缩进体现层级关系，上下文压缩时输入框底部出现提示线。

## 新功能：AI 提问面板与对话引导

Agent 在调查过程中需要用户回答时，提问面板现在直接出现在输入框区域——不再弹出一个侧边面板打断操作。输入框切换为轻量面板，支持推荐选项、单选、自由输入和多步进度导航。右侧详情面板只在主动点击工具调用时打开。

对话引导让运维人员可以在对话过程中主动调整 Agent 的分析方向——指出关注重点、澄清假设、或要求对某个组件深入排查——让调查从一次性问答变成真正的协作对话。

## 新功能：应用初始化、Dashboard 与数据溯源

应用初始化一步加载连接器、资源及其关系，支持快速绑定（一键关联数据源）和精确绑定（字段级映射与过滤）。

在分析会话中可直接生成 HTML 和 YAML 格式的 Dashboard，检查指定片段，并在 Castrel 内完成 Grafana Dashboard 的新建、更新和回滚。每个结论均可追溯数据来源，点击即可查看驱动的具体指标、日志或事件。

## 完整发版清单

### feat
- Chat 消息区收窄阅读宽度，新增用户消息头像与 hover 时间戳/复制操作。
- Agent 执行过程消息默认折叠，收起行展示步数摘要与耗时。
- 工具调用展示改为更轻量的显示样式，点击跳转右侧详情面板查看详情，同类工具多次调用合并计数。
- 新增右侧会话信息卡片，聚合展示来源、子智能体、产出物和待办，根据可用宽度自适应显示。
- 右侧详情面板 Tab 进入历史会话自动聚焦最后一个产出物，Tab 关闭改为 hover 显示 × 图标。
- 文档和知识 Tab 展示实际文档名称，不再显示泛化类型名。
- 侧边栏对话标题去除图标占位，子 Agent 对话额外缩进体现层级关系。
- Chat 输入框底部改为更轻量的样式，自动压缩上下文时展示横向提示线。
- 输入框新增 `/` 快捷键触发 Chat 模式切换，取代原有按钮下拉选择方式。
- Agent 提问面板迁移至输入框区域，重构为中断式问答面板，支持推荐选项与自由输入。
- 新增对话引导能力，运维人员可主动控制 Agent 分析方向。
- 新增应用初始化能力，支持快速绑定与精确绑定两种数据接入模式。
- 新增 Dashboard 生成（HTML + YAML 双版本），支持指定片段分析。
- 新增 Grafana Dashboard 生命周期管理——新建、更新与回滚。
- 新增数据溯源能力，每个结论均可追溯至原始数据来源。
- RCA 故障传播拓扑叠加全局 Application 拓扑，三层视觉区分故障节点、受影响对象与正常节点。
- Incident Pattern MVP 上线，支持从历史故障中提取、匹配与复用故障模式。
- RCA 上下文管理重构，所有节点统一使用含完整元数据的 App 相关上下文传递。
- RCA Agent 完成插件化并与 RCA 首页 Copilot 打通，支持历史 Incident 查询与趋势分析。
