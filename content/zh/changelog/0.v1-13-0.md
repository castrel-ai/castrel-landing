## 新功能：Chat 对话体验全面升级

本次对 Chat 页面进行了覆盖面最广的一次交互重塑，涉及消息阅读区、任务过程展示、输入框、Canvas Tab 和侧边栏五个维度。

**消息阅读区与操作体验**方面，收窄了左侧阅读宽度，提升长对话场景下的阅读密度；Agent 最终输出去掉了错误的引用式缩进；用户消息右侧新增头像展示；User / Agent 消息 hover 时，在消息下方显示时间与复制操作，复制内容仅包含正文，不含工具调用的输入/输出。

**任务过程折叠**是本次最大的视觉变化。Agent 执行过程消息现在默认折叠，收起行显示本轮执行摘要与耗时（如"执行了 X 步 / Worked for {duration}"），展开/收起附有轻量过渡动效。进行中或被中断的任务不可折叠，确保异常状态始终可见。

**工具调用展示**改为更轻的 ghost 样式；点击工具调用跳转到右侧 Canvas 查看详情，不再行内展开；多次同 toolset 调用自动合并显示（如"使用 Prometheus × 3"）；Todo 工具在过程消息中隐藏，减少重复信息干扰。

**Canvas Tab** 进入历史会话时自动聚焦最后一轮的最后一个 artifact；可关闭的 Tab 改为 hover 时左侧图标变为 × 的轻量关闭方式；文档和知识 Tab 展示对应文档名称，而非泛化类型名。

**侧边栏任务列表**方面，普通对话去掉图标占位，标题左边缘与分组标题对齐；子 Agent 对话额外缩进一个图标宽度，清晰体现任务从属层级关系。

## 新功能：AI 提问交互重构

当 Agent 需要向用户提问时，之前的交互方式会在右侧弹出 Canvas 卡片，打断对话节奏，且输入框仍显示"AI 正在生成回复"，提示语存在歧义。

本次将 `ask_user_question` 的用户交互迁移到输入框区域，改为**中断式问答面板**。Agent 等待用户回答时，输入框区域切换为轻量问答面板，用户在当前对话节奏中即可完成回答，无需切换到右侧卡片。面板支持推荐选项、普通选项和自由输入；多个问题时在 header 显示当前进度（如 1/3）并支持左右切换；支持 ESC 退出。右侧 Canvas 不再自动打开，仅在用户主动点击工具调用查看详情时打开。

这一机制作为通用的 input interrupt 插槽下沉到输入框组件，后续其他需要等待用户输入的工具也可复用。

## RCA Studio 能力增强

本次对 RCA 故障分析工作台进行了四个方向的系统性升级。

**故障传播拓扑升级**：在现有故障路径基础上叠加全局 Application 拓扑，通过三层视觉层次清晰区分故障全貌——故障传播节点标红、受影响对象标黄、正常节点保持默认样式。排查人员可一眼看清故障传播核心与影响扩散范围，不再需要在多个视图间切换。

**Incident Pattern MVP**：支持从历史故障中提取、匹配、存储和复用故障模式（Pattern）。有历史 Pattern 时，精准命中后直接复用推断链路，显著加速 RCA 过程；无历史先例时，通过机制命中（如资源耗尽、级联失败、配置漂移等抽象模式）缩小假设空间，均未命中时退回原有推理流程。

**故障上下文管理重构**：所有 RCA 节点统一使用 App 相关上下文，包含原始元数据、App 信息、上游线索以及已排查的假设/结论/证据，确保整个排查过程有完整的上下文传递，结论更连贯可追溯。

**RCA Agent 插件化**：RCA Agent 完成插件化改造，并与 RCA 首页 Copilot 打通。用户现在可以通过 Copilot 对历史 Incident 进行信息查询、数量统计、趋势分析、综合分析和周期报告生成，从单次故障排查扩展为可持续运营的故障分析平台。
