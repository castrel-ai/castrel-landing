## 新增内置任务

运维团队的知识往往分散在个人经验中，已接入的应用、服务和连接器缺少结构化的业务语义（用途、Owner、依赖关系、环境归属等），导致 AI 在排障时缺少关键上下文。本次发版新增内置自动化任务「系统认知补全」来解决这一问题：它自动扫描已接入资源，识别会妨碍排障效率的知识盲区，并以结构化问卷引导团队补充。补全后的知识自动关联到对应资源，确保每次故障响应时 AI 都能获得足够的业务上下文。

## 完整发版清单

### feat
- 仪表盘新增对 MCP 连接器的支持。
- 应用 CI 获取工具时，正确读取自定义接入配置中的 MCP 工具。
- 子智能体支持通过环境变量配置自定义连接器类型，允许调用 MCP 实例。
- 知识标签显示具体 MCP 实例名，便于区分不同实例。
- 根因分析报告支持给出多个候选根因，提升复杂场景下的排查效率。
- 新增系统认知补全自动化任务，支持知识缺口扫描、结构化问卷生成与长期知识沉淀。

### bugfix
- 修复 write_document 工具调用可视化图表未正确渲染的问题。
- 修复时序图数据点之间存在 null 值时连线中断的问题。
- 修复邮箱验证码与邀请加入空间的 SMTP 证书验证问题。
- 修复 GitHub 集成在国内及 UAT 环境下的配置问题。
