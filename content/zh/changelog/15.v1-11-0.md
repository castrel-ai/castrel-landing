## 完整发版清单

### feat
- Incident Studio 适应性优化，复用通用 Graph 与 Chat 框架，移除未完成功能入口。
- 自动化首页改用新 Tab Layout 布局，移除顶部输入框。
- 海外站点集成渠道适配，区分中外站点 IM 展示并启用品牌官方 Logo。
- 新增 SaaS 企业版用户等级，支持在 Admin 中自定义 Token 配额与自动化数量。
- 服务列表支持通过多选框批量添加应用。
- 集成数据同步时支持关联应用选项。
- 对话压缩时向用户展示提示信息。
- 优化自动化创建及编辑页面表单显示。
- 健康巡检模式调整，首页与创建页面隐藏巡检入口，编辑页面锁定。
- 补充 Tempo、Loki、ClickHouse、VictoriaMetrics、SkyWalking、Zabbix、K8s、Grafana 共 8 个插件的 Skills 实现。

### bugfix
- 修复 SkyWalking 集成对 8.x 版本兼容性问题。
- 修复 SkyWalking 同步依赖出现不属于 Service/Infra 的异常依赖。
- 修复大模型 API 缓存 Token 计数不准导致过早压缩与计费偏差的问题。
- 修复故障排查未传连接器时不调用子 Agent 并无限排查的问题。
- 修复插件页面 Demo Connector 快捷接入功能异常。
