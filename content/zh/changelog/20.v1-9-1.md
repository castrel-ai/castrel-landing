## 完整发版清单

### feat
- Chat 调用 get_knowledge 工具后，Canvas 面板自动展示 Knowledge 详情内容。
- Chat 会话中实现连接器数据查询结果的可视化展示。
- Proxy MCP 工具执行优化，支持长连接和 stdio 模式，避免每次新建连接。
- Proxy 支持 Docker 化部署，镜像内置 MCP 运行环境；ComputerMcp 分发逻辑优化，readonly MCP 增加 UI 标记。

### bugfix
- 修复集成安装完成后排序位置异常跳至首位的问题。
- 修复分享数据探索任务查看时仍需登录的问题。
- 修复集成通信工具时分类标签错误显示为"连接器"的问题。
