## 新功能：Incident Studio 与 Application 模块全面升级

全新的 Incident Studio 模块正式上线，为事件驱动的调查与协作流程提供专属工作空间。创建任务时可指定所属 Studio，与 Application、当前模式、触发模式三个维度正交，实现更精细的任务归属与上下文隔离。Incident Studio 提供以事件为中心的调查视角，将告警、日志、变更等多源信息汇聚到统一的事件时间线中，帮助团队快速定位根因。相比之前分散在不同模块的调查入口，Studio 将相关上下文集中呈现，减少跨模块切换的信息断裂。

## Application 模块全面升级

Application 模块完成了核心用户旅程的全面重构。重新梳理了模块的核心入口、关键节点与状态流转，优化信息架构与交互路径，降低使用摩擦。同时引入健康巡检能力，在应用页面可直接创建并执行健康巡检任务，并展示近 30 天健康状态趋势。在新建任务页面中新增了健康巡检模式，执行完成后支持一键创建自动化并绑定到当前应用，将巡检结果无缝转化为持续监控策略。

## 完整发版清单

### feat
- 统一所有 AI 对话入口的输入框组件，支持任务类型、所属应用、连接器与代理节点的统一配置。
- 新增任务类型切换能力，支持通用、假设驱动调查、数据探索三种模式及各自独立的扩展数据与工具。
- 统一插件模块架构，将连接配置、工具、技能、知识、通道、事件订阅、自动化模版与上下文同步合并为统一的插件体系。
- 迁移 22 项插件至新架构，新增 K8s、Zabbix、Tempo、SkyWalking、透视宝的资源同步能力。
- 通讯渠道整体迁移至插件体系，新增安装状态管理。
- 新增昆仑联通自建 AIOPS 平台消息渠道集成，通过 Feature Flags 管理。
- 选择应用后向 General Graph 注入 Application 简介作为全局上下文，取代原有的实体简介。
- Automation 执行统一到 GeneralChatGraph，增加 application_id 与 trigger_type 支持。

### bugfix
- 修复 RCA Studio 诊断首次导航至会话页面显示空白，需手动刷新才能渲染内容的问题。
- 优化应用列表零数据场景的全局空状态引导，新增模块用途说明与创建入口。
- 修复应用模块多项交互问题：创建弹窗与其他实体保持一致、列表中"所属应用"字段展示、部署关系与依赖关系的详情和编辑样式统一。
- 回滚实体唯一性校验至原有范围，修复会话中 @mention 功能异常。
