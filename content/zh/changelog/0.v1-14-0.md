## 新功能：Agent 运行权限策略

在发起对话时，你可以为本次 Agent 运行选择权限策略，精确控制 Agent 能够执行的操作范围，让自动化运维在安全与效率之间取得平衡。

权限策略提供四个级别：**只读**模式下 Agent 不会执行 Connector 与 Castrel Proxy 节点的写操作，但提交 CI、写入知识等系统内部操作仍可正常进行；**请求批准**模式会在每次写操作和 Proxy 节点写操作前请求你的确认；**替我批准**模式由 AI 代为批准常规操作，仅在涉及危险操作时才停下来请求你的确认；**完全访问**模式则无需人工批准，适用于完全信任的自动化场景。

## 新功能：主题切换与外观持久化

Castrel 现已支持主题切换，你可以在深色与浅色主题之间自由切换，并调整界面与聊天区域的字号。聊天、任务详情、子智能体视图、Canvas 文档与终端转录均统一跟随设置，确保各类视图在不同主题下保持一致的可读性与视觉风格。

外观设置升级为账号级持久化配置。登录后系统会优先从服务端加载你的外观偏好，修改后自动保存，刷新页面、重新登录或切换设备时都会自动恢复，不再受限于单一浏览器。未登录或服务端不可用时，界面仍会回退到本地设置以保证可用性。设置面板的主题操作也统一改为页头的保存与取消。

## 新增 1 项集成，增强 1 项插件

- **新增**：企业微信（支持作为自动化通知渠道）。
- **增强**：华为云插件（新增应用托管、ECS 启停、告警规则启停与标签绑定等操作）。
