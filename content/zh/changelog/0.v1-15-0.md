## 新功能：运维斜杠指令

在对话输入框输入斜杠，就能像聊天一样发起部署、巡检与自动值守，无需切换工具或记忆复杂命令。本次新增 `/deploy`、`/health`、`/loop`、`/goal` 四个指令，覆盖从一次性操作到长期盯守的常见运维场景。

`/deploy` 和 `/health` 都针对你选定的应用执行，并以知识库里的文档为唯一依据，确保 Agent 按你既定的规范行事、不擅自编造步骤。输入 `/deploy 应用名` 后，Agent 会读取该应用的部署文档，按文档约定的流程发起上线，并回传部署链接、流水线编号，以及出错信息与后续建议。`/health` 则依据应用的 SLO 文档采集监控信号，生成一份结构化健康报告：总体状态、各项 SLO 达标情况、错误预算消耗、活跃异常、根因提示与建议动作，让你一眼看清应用是否健康。

`/loop` 把任意指令或提示变成定时重复任务，例如 `/loop 5m /health payment-service` 每 5 分钟巡检一次支付服务。任务会先立即执行一次，随后按设定的时间间隔重复，7 天后自动停止，也可随时手动取消，适合持续盯守部署状态或告警。

`/goal` 为当前对话设定一个完成条件，例如「排查所有 503 错误」。设定后 Agent 会立即着手并不断评估进展，条件满足就自动结束对话，无需手动收尾；输入 `/goal clear` 可随时清除目标。
