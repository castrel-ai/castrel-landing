## 概览

- **连接器名称**：`prometheus`
- **支持的 API 版本**：Prometheus HTTP API v1
- **支持的服务端版本**：Prometheus v3.0.0 及以上
- **官方文档**：[Prometheus Docs](https://prometheus.io/docs/introduction/overview/)

## 配置

要使用 Prometheus 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 用于标识该连接器实例的名称 |
| `base_url` | 是 | Prometheus 服务的基础 URL（例如 `http://prometheus:9090`） |
| `auth_type` | 是 | 设置为 `none` 或 `basic` |
| `username` | 否 | Basic Auth 用户名 |
| `password` | 否 | Basic Auth 密码 |
| `verify_ssl` | 否 | 是否校验证书（默认：true） |

## 可用工具

该连接器提供一整套用于指标分析和元数据探索的工具。

- **指标查询**：执行 PromQL 查询（即时查询与区间查询）
- **元数据发现**：列出指标名、标签名、标签值和时序
- **告警能力**：获取当前活动告警和告警规则
- **目标状态**：检查被抓取目标的健康状态和运行情况

## @ 提及

支持在对话中 `@prometheus` 快速选择指标，通过三列钻取（指标名 → 标签 → 操作）选择目标。
