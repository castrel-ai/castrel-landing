## 概览

- **连接器名称**：`telegram`
- **支持的 API 版本**：Telegram Bot API
- **官方文档**：[Telegram Bot API 文档](https://core.telegram.org/bots/api)

## 配置

要使用 Telegram 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 连接器实例的展示名称 |
| `token` | 是 | Telegram Bot Token（通过 [@BotFather](https://t.me/BotFather) 创建机器人后获取） |

> Bot Token 格式为 `{bot_id}:{secret}`，例如 `1234567890:AAxxxxxx`。

## 可用工具

该连接器提供 Telegram 机器人消息发送与通知能力。

- **消息发送**：向指定 Chat ID（用户、群组或频道）发送文本消息
- **Markdown 消息**：发送支持 Markdown 格式的富文本通知
- **告警推送**：将监控告警与报告内容推送到 Telegram 群组或个人
- **文件发送**：发送文档、图片等文件附件
