## 概览

- **连接器名称**：`graylog`
- **支持的 API 版本**：Graylog REST API
- **支持的服务端版本**：Graylog v6.0.0 及以上
- **官方文档**：[Graylog Docs](https://go2docs.graylog.org/current/home.htm)

## 配置

要使用 Graylog 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 用于标识该连接器实例的名称 |
| `base_url` | 是 | Graylog API 的基础 URL（例如 `http://graylog:9000/api`） |
| `access_token` | 是 | 用于认证的 API Access Token |
| `verify_ssl` | 否 | 是否校验证书（默认：true） |

## 可用工具

该连接器提供用于日志搜索和 stream 探索的工具。

- **日志搜索**：按相对时间、绝对时间或关键词搜索日志
- **Stream 发现**：列出可用的 stream
- **字段发现**：获取可用字段列表
