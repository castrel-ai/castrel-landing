## 概览

- **连接器名称**：`new_relic`
- **支持的 API 版本**：New Relic REST API v2、NerdGraph（GraphQL）
- **官方文档**：[New Relic REST API v2](https://docs.newrelic.com/docs/apis/rest-api-v2/get-started/introduction-new-relic-rest-api-v2/)

## 配置

要使用 New Relic 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `api_key` | 是 | New Relic User API Key |
| `account_id` | 否 | 默认账户 ID（用于 NRQL 查询） |
| `region` | 否 | 区域：`US`（默认）或 `EU` |
| `base_url` | 否 | API 基础地址（美国站：`https://api.newrelic.com`，欧洲站：`https://api.eu.newrelic.com`） |
| `graphql_url` | 否 | NerdGraph 端点（默认：`https://api.newrelic.com/graphql`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> User API Key 可在 New Relic「User menu → API keys」中创建。

## 可用工具

该连接器提供一整套 New Relic 全栈可观测性数据查询工具。

- **APM 查询**：获取应用性能指标、事务与错误率
- **日志检索**：在 New Relic Logs 中全文搜索日志
- **NRQL 查询**：执行 New Relic 查询语言（NRQL）自定义分析
- **链路追踪**：查询分布式链路数据（Distributed Tracing）
- **基础设施**：获取主机、K8s 集群与云集成状态
- **告警管理**：查询告警策略、条件与 Incident 记录
- **Dashboard 查询**：获取 Dashboard 列表与图表数据
- **Synthetic 监控**：查询合成监控执行结果
