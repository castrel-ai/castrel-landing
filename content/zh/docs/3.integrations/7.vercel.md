## 概览

- **连接器名称**：`vercel`
- **协议**：Model Context Protocol（MCP）
- **官方文档**：[Vercel API 文档](https://vercel.com/docs/rest-api)

## 配置

Vercel 使用 OAuth 2.0 授权流程，无需手动填写密钥。

在 Castrel 工作区中，点击「添加连接器」→「Vercel」→「Connect with Vercel」，授权完成后即可使用。

> OAuth2 凭据由 Castrel 统一管理，权限范围覆盖你授权的 Vercel 团队与项目。

## 可用工具

该连接器通过 MCP 协议提供 Vercel 项目与部署管理能力。

- **项目查询**：列举团队下的项目与配置信息
- **部署查询**：获取部署历史、状态与构建日志
- **函数日志**：获取 Serverless Function / Edge Function 运行日志
- **域名管理**：查询域名绑定与 DNS 配置
- **环境变量**：查看项目环境变量名称（值字段脱敏）
