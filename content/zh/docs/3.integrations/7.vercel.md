## 概览

- **连接器名称**：`vercel`
- **支持的 API 版本**：Vercel REST API
- **官方文档**：[Vercel API Docs](https://vercel.com/docs/rest-api)

## 可用工具

该连接器提供一组用于部署管理和分析的工具。

- **运行时日志**：`vercel_get_deployment_runtime_logs`，用于获取指定部署的运行时日志（error、warning、info）
- **项目管理**：列出并查看 Vercel 项目
- **部署管理**：列出部署并获取部署详情
