## 概览

- **连接器名称**：`jenkins`
- **支持的 API 版本**：Jenkins Remote Access API
- **官方文档**：[Jenkins Remote Access API](https://www.jenkins.io/doc/book/using/remote-access-api/)

## 配置

要使用 Jenkins 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 是 | Jenkins 服务器地址（例如 `http://jenkins.example.com`） |
| `username` | 是 | Jenkins 用户名 |
| `api_token` | 是 | Jenkins API Token（在用户设置中生成） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> API Token 可在 Jenkins「用户 → Configure → API Token → Add new Token」中生成。

## 可用工具

该连接器提供一整套用于 Jenkins CI/CD 流水线管理的工具。

- **Job 查询**：列举 Job 列表与获取 Job 详情
- **构建历史**：查询构建记录、状态与控制台输出
- **流水线状态**：获取 Pipeline 各阶段执行状态
- **构建触发**：远程触发 Job 构建并传入参数
- **队列查询**：查看当前构建队列状态
