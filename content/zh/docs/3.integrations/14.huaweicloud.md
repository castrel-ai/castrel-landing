## 概览

- **连接器名称**：`huaweicloud`
- **支持的 API 版本**：华为云 OpenAPI（最新版）
- **官方文档**：[华为云 API Explorer](https://console.huaweicloud.com/apiexplorer)

## 配置

要使用华为云工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `access_key_id` | 是 | AK（Access Key ID） |
| `secret_access_key` | 是 | SK（Secret Access Key） |
| `region` | 是 | 区域标识符（例如 `cn-north-4`） |
| `project_id` | 是 | 项目 ID |
| `domain_id` | 否 | 账号 ID（跨项目查询时需要） |
| `enterprise_project_id` | 否 | 企业项目 ID（默认：`all_granted_eps`） |
| `apm_business_id` | 否 | APM 业务 ID |
| `language` | 否 | 响应语言（默认：`zh_cn`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |
| `service_endpoints` | 否 | 各服务的自定义接入点（用于私有云或专属云场景） |

## 可用工具

该连接器提供一整套华为云只读访问工具。

- **LTS 日志查询**：检索华为云日志服务（LTS）中的应用与系统日志
- **CES 指标查询**：获取云眼（CES）指标时序数据
- **CES 告警查询**：获取当前活跃告警与告警历史
- **APM 链路追踪**：查询应用链路数据与性能分析
- **RMS 资源清单**：列举与查询云资源（ECS、RDS、VPC 等）
- **BSS 账单分析**：获取费用账单与成本分析数据
