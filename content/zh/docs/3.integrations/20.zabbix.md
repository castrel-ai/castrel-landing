## 概览

- **连接器名称**：`zabbix`
- **支持的 API 版本**：Zabbix API v6.0 / v7.0
- **官方文档**：[Zabbix API 文档](https://www.zabbix.com/documentation/current/zh/manual/api)

## 配置

要使用 Zabbix 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 是 | Zabbix Web 界面地址（例如 `http://zabbix.example.com`） |
| `auth_type` | 是 | 认证方式：`api_key`（推荐，Zabbix 5.4+）或 `basic` |
| `api_key` | 否 | API Token（`auth_type=api_key` 时必填，在「管理 → API Token」中创建） |
| `username` | 否 | 用户名（`auth_type=basic` 时必填） |
| `password` | 否 | 密码（`auth_type=basic` 时必填） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> 推荐使用 API Token 认证（Zabbix 5.4+），在 Zabbix 管理界面「管理 → 常规 → API Token」中创建。

## 可用工具

该连接器提供一整套 Zabbix 监控数据查询工具。

- **主机查询**：列举主机列表、状态与监控配置
- **触发器监控**：获取当前触发的告警触发器与严重程度
- **问题查询**：检索问题列表（Problem）与告警历史
- **指标数据**：获取主机监控项的历史与趋势数据
- **模板管理**：查询主机模板与监控项配置
