## 概览

- **连接器名称**：`clickhouse`
- **支持的 API 版本**：ClickHouse HTTP API v1
- **支持的服务端版本**：ClickHouse 22.0 及以上
- **官方文档**：[ClickHouse HTTP 接口](https://clickhouse.com/docs/zh/interfaces/http)

## 配置

要使用 ClickHouse 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 是 | ClickHouse HTTP API 地址（例如 `http://localhost:8123`） |
| `username` | 是 | ClickHouse 用户名（默认为 `default`） |
| `password` | 是 | 用户密码 |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供一整套用于 ClickHouse 数据查询与探索的工具。

- **SQL 查询**：执行任意 SELECT 查询，支持 ClickHouse 方言与函数
- **数据库探索**：列举数据库、表和列结构信息
- **日志检索**：按时间范围与条件过滤日志类数据
- **聚合分析**：执行高性能聚合统计与时序聚合查询
- **表元数据**：查询表行数、存储大小等元信息
