## 概览

- **连接器名称**：`loki`
- **支持的 API 版本**：Grafana Loki HTTP API v1
- **支持的服务端版本**：Grafana Loki v3.0.0 及以上
- **官方文档**：[Grafana Loki Docs](https://grafana.com/docs/loki/latest/)

## 配置

要使用 Loki 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 用于标识该连接器实例的名称 |
| `base_url` | 是 | Loki 服务的基础 URL（例如 `http://loki:3100`） |
| `auth_type` | 是 | 设置为 `none` 或 `basic` |
| `username` | 否 | Basic Auth 用户名 |
| `password` | 否 | Basic Auth 密码 |
| `org_id` | 否 | 多租户 Loki 的组织 ID（会设置 `X-Scope-OrgID` 请求头） |
| `verify_ssl` | 否 | 是否校验证书（默认：true） |

## 可用工具

该连接器提供一整套用于 Loki 日志查询的工具。

- **日志查询**：执行 LogQL 即时查询（`/loki/api/v1/query`）
- **区间查询**：执行 LogQL 区间查询获取时序日志流
- **标签探索**：列举可用的标签名与标签值
- **流检索**：按标签选择器筛选日志流

## @ 提及

支持在对话中 `@loki` 快速选择日志流标签，通过三列钻取（标签名 → 标签值 → 操作）选择目标。
