## 概览

- **连接器名称**：`qingfanyun`
- **支持的 API 版本**：轻帆云 ITSM API v1
- **官方文档**：[轻帆云官网](https://www.cloudwise.com)

## 配置

要使用轻帆云工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 是 | API 基础地址（例如 `https://itsm.cloudwise.com/docp/gatewayApi/dosm`） |
| `account_id` | 是 | 二级租户 ID |
| `top_account_id` | 是 | 顶级租户 ID（无子租户时与 `account_id` 相同） |
| `user_id` | 是 | 用户 ID |
| `app_key` | 是 | 应用 Key |
| `app_secret` | 是 | 应用 Secret |
| `auth_type` | 否 | 认证方式，默认：`secret` |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供轻帆云 ITSM 工单全生命周期管理工具。

- **流程模板查询**：列举可用的工单流程模板
- **工单创建**：根据流程模板创建新工单
- **工单查询**：按 ID、状态、时间范围检索工单
- **工单更新**：更新工单字段与状态
- **工单流转**：提交、转派与关闭工单
