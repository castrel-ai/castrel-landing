## 概览

- **连接器名称**：`volcengine`
- **支持的 API 版本**：火山引擎 OpenAPI（最新版）
- **官方文档**：[火山引擎 API 文档](https://api.volcengine.com/api-docs)

## 配置

要使用火山引擎工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `access_key_id` | 是 | Access Key ID |
| `secret_access_key` | 是 | Secret Access Key |
| `region` | 是 | 区域标识符（例如 `cn-beijing`、`ap-southeast-1`） |
| `session_token` | 否 | 临时凭证 Session Token（使用 STS 时填写） |
| `base_url` | 否 | API 基础地址（默认：`https://open.volcengineapi.com`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |
| `service_versions` | 否 | 各服务的 API 版本覆盖配置（例如 ECS、CloudMonitor、TLS 等） |

## 可用工具

该连接器提供一整套火山引擎只读访问工具。

- **TLS 日志查询**：检索火山引擎日志服务（TLS）中的应用与系统日志
- **CloudMonitor 指标**：获取云监控指标时序数据
- **告警查询**：获取当前活跃告警与历史记录
- **APM 链路追踪**：查询分布式链路数据
- **ECS 资源清单**：列举与查询 ECS 实例信息
- **账单分析**：获取费用账单与成本数据
