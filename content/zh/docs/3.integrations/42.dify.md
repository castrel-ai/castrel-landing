## 概览

- **连接器名称**：`dify`
- **协议**：Model Context Protocol（MCP）
- **官方文档**：[Dify API 文档](https://docs.dify.ai/guides/application-publishing/developing-with-apis)

## 配置

要使用 Dify 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 连接器实例的展示名称 |
| `base_url` | 是 | Dify App 的 MCP 端点 URL（例如 `https://api.dify.ai/mcp/server/{secret}`） |

> MCP 端点 URL 可在 Dify 应用的「发布 → MCP」设置中获取。

## 可用工具

Dify 连接器基于 MCP 协议，在建立连接后自动发现 Dify 应用暴露的工具。

- **工作流调用**：触发 Dify 工作流并获取执行结果
- **知识库检索**：通过 Dify 知识库 RAG 能力查询文档内容
- **智能体交互**：调用 Dify 智能体进行多轮对话或任务处理
- **工具自动发现**：连接后自动列举 Dify 应用暴露的所有 MCP 工具
