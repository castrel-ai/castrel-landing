## 概览

- **连接器名称**：`sentry`
- **支持的 API 版本**：Sentry REST API v0
- **官方文档**：[Sentry API 文档](https://docs.sentry.io/api/)

## 配置

要使用 Sentry 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `bearer_token` | 是 | Sentry Auth Token（在「Settings → Account → API Tokens」中生成） |
| `base_url` | 否 | API 基础地址（默认：`https://sentry.io`；自托管时填写自定义地址） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供一整套 Sentry 错误监控与性能分析工具。

- **组织与项目**：列举组织、项目配置与团队信息
- **Issue 查询**：按状态、优先级、时间范围检索 Error Issue
- **事件检索**：获取 Issue 关联的错误事件详情与堆栈信息
- **时序统计**：获取错误率、事件数量的时序聚合数据
- **告警规则**：查询告警规则与通知配置
