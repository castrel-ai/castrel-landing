## 概览

- **连接器名称**：`pagerduty`
- **支持的 API 版本**：PagerDuty REST API v2
- **官方文档**：[PagerDuty API 参考](https://developer.pagerduty.com/api-reference/)

## 配置

要使用 PagerDuty 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `api_token` | 是 | PagerDuty API Token（在「User Settings → API Access → Create New API Key」中生成） |
| `from_email` | 否 | 写操作时（确认/解决/添加备注）作为 `From` 请求头使用的邮箱地址 |
| `base_url` | 否 | API 基础地址（默认：`https://api.pagerduty.com`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供一整套 PagerDuty 事件管理与运维自动化工具。

- **Incident 管理**：查询、确认、解决 Incident 并添加备注
- **Alert 查询**：获取告警列表与详情
- **On-Call 查询**：查看当前值班人员与值班计划
- **服务管理**：列举服务、集成与上游依赖
- **日志条目**：获取 Incident 日志流水与时间线
