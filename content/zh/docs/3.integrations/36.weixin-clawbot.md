## 概览

- **连接器名称**：`weixin_clawbot`
- **支持的 API 版本**：企业微信 API v3
- **官方文档**：[企业微信开发文档](https://developer.work.weixin.qq.com/document/path/90664)

## 配置

要使用企业微信工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 连接器实例的展示名称 |
| `token` | 是 | 企业微信应用的 Access Token 或 Bot Webhook Token |
| `user_id` | 是 | 默认接收消息的用户 ID 或群 ID |

## 可用工具

该连接器提供企业微信消息发送与通知能力。

- **消息发送**：向指定用户、部门或标签组发送文本消息
- **Markdown 消息**：发送 Markdown 格式的富文本通知
- **告警推送**：将监控告警与报告内容推送到企业微信
- **图文消息**：发送图文卡片消息
