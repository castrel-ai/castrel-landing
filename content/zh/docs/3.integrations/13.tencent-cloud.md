## 概览

- **连接器名称**：`tencent_cloud`
- **支持的 API 版本**：腾讯云 CAM API（最新版）
- **官方文档**：[腾讯云 API 文档](https://cloud.tencent.com/document/api)

## 配置

要使用腾讯云工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `secret_id` | 是 | CAM SecretId（在「访问管理 → API 密钥管理」中创建） |
| `secret_key` | 是 | CAM SecretKey |
| `region` | 是 | 区域标识符（例如 `ap-guangzhou`、`ap-beijing`） |
| `token` | 否 | 临时凭证 Token（使用 STS 角色时填写） |
| `base_url` | 否 | API 基础地址（默认：`https://tencentcloudapi.com`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> 建议创建只读子账号，授予 `QcloudMonitorReadOnlyAccess`、`QcloudCLSReadOnlyAccess` 等只读策略。

## 可用工具

该连接器提供一整套腾讯云只读访问工具。

- **云监控（CM）**：查询指标数据与告警历史
- **日志服务（CLS）**：检索与分析日志数据
- **云资源发现**：列举 CVM、RDS、CKE 等资源清单
- **费用分析**：获取账单明细与成本数据
