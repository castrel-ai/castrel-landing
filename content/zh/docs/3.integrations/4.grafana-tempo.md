## 概览

- **连接器名称**：`tempo`
- **支持的 API 版本**：Grafana Tempo HTTP API
- **支持的服务端版本**：Grafana Tempo v2.0.0 及以上
- **官方文档**：[Grafana Tempo Docs](https://grafana.com/docs/tempo/latest/)

## 配置

要使用 Tempo 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 用于标识该连接器实例的名称 |
| `base_url` | 是 | Tempo 服务的基础 URL（例如 `http://tempo:3200`） |
| `auth_type` | 是 | 设置为 `none` 或 `basic` |
| `username` | 否 | Basic Auth 用户名 |
| `password` | 否 | Basic Auth 密码 |
| `verify_ssl` | 否 | 是否校验证书（默认：true） |

## 可用工具

该连接器提供链路检索与分析工具。

- **链路获取**：按 trace ID 获取指定链路
- **链路搜索**：使用 TraceQL 或筛选条件搜索链路
- **元数据**：列出 tag 名与取值，帮助你构造筛选条件
- **指标**：查询从链路衍生出的指标（RED metrics）
