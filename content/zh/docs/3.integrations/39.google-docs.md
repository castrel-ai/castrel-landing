## 概览

- **连接器名称**：`google_docs`
- **支持的 API 版本**：Google Docs API v1、Google Drive API v3
- **官方文档**：[Google Docs API 文档](https://developers.google.cn/workspace/docs/api/how-tos/overview?hl=zh-cn)

## 配置

要使用 Google Docs 工具，你需要配置一个包含以下字段的 Connector（服务账号模式）：

| 字段 | 必填 | 说明 |
|------|------|------|
| `service_account_email` | 是 | 服务账号的电子邮件地址 |
| `service_account_private_key` | 是 | 服务账号的 RSA 私钥（PEM 格式） |
| `service_account_private_key_id` | 是 | 服务账号私钥 ID |
| `service_account_project_id` | 是 | GCP 项目 ID |
| `service_account_token_uri` | 否 | Token 端点（默认：`https://oauth2.googleapis.com/token`） |
| `instance_name` | 否 | 连接器实例展示名称（默认：`Google Docs Service Account`） |

> 服务账号需要具有目标文档的「查看者」权限，或通过 Google Workspace 域级委托授权。

## 可用工具

该连接器提供 Google Docs 与 Google Drive 的只读访问能力。

- **文档读取**：获取指定 Google Docs 文档的正文内容
- **文档搜索**：在 Google Drive 中按名称或内容搜索文档
- **文件列举**：列举指定目录下的文档与文件
- **权限查询**：查看文档的共享与权限设置
