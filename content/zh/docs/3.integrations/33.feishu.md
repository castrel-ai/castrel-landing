## 概览

- **连接器名称**：`feishu`
- **支持的 API 版本**：飞书开放平台 API v3
- **官方文档**：[飞书开放平台文档](https://open.feishu.cn/document/home/index)

## 配置

要使用飞书工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 连接器实例的展示名称 |
| `app_id` | 是 | 飞书应用的 App ID |
| `app_secret` | 是 | 飞书应用的 App Secret |

> 在[飞书开放平台](https://open.feishu.cn/)创建自建应用后，即可获取 App ID 与 App Secret。

## 可用工具

该连接器提供飞书消息通知与机器人交互能力。

- **消息发送**：向指定用户、群组或会话发送文本与卡片消息
- **消息接收**：接收用户发给机器人的消息并触发处理流程
- **用户查询**：通过邮箱、手机号查询飞书用户信息
- **群管理**：查询群成员与群信息
- **通知推送**：将告警、报告等内容推送到飞书群或个人
