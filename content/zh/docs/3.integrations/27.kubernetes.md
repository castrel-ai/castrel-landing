## 概览

- **连接器名称**：`kubernetes`
- **支持的 API 版本**：Kubernetes API v1
- **官方文档**：[Kubernetes API 参考](https://kubernetes.io/docs/reference/kubernetes-api/)

## 配置

要使用 Kubernetes 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 是 | Kubernetes API Server 地址（例如 `https://10.104.0.219:6443`） |
| `auth_type` | 是 | 认证方式：`bearer`（ServiceAccount Token）或 `basic` |
| `bearer_token` | 否 | ServiceAccount Bearer Token（`auth_type=bearer` 时必填） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（集群内通常关闭，默认：`false`） |

> 推荐使用具有只读权限的 ServiceAccount Token 进行认证，通过 RBAC 授予 `view` ClusterRole。

## 可用工具

该连接器提供一整套用于 Kubernetes 集群状态监控与资源查询的工具。

- **Pod 查询**：列举 Pod 状态、资源使用与日志
- **Deployment 管理**：查询 Deployment、ReplicaSet 状态与历史
- **Node 信息**：获取节点状态、资源容量与健康情况
- **事件查询**：获取集群事件（Warning/Normal）列表
- **Service 与 Ingress**：查询网络资源配置与状态
- **ConfigMap / Secret**：查看配置资源（Secret 值脱敏）
