## 概览

- **连接器名称**：`aws`
- **支持的 API 版本**：CloudWatch API、CloudWatch Logs Insights API、Cost Explorer API
- **官方文档**：[AWS CloudWatch 文档](https://docs.aws.amazon.com/cloudwatch/)

## 配置

要使用 AWS 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `aws_access_key_id` | 是 | IAM Access Key ID |
| `aws_secret_access_key` | 是 | IAM Secret Access Key |
| `region` | 是 | AWS 区域（例如 `us-east-1`、`ap-northeast-1`） |
| `session_token` | 否 | STS 临时凭证 Session Token（使用 IAM Role 时填写） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`60`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> 建议创建最小权限的 IAM 用户，只授予 `cloudwatch:Get*`、`cloudwatch:List*`、`logs:*`、`ce:*` 等只读权限。

## 可用工具

该连接器提供一整套用于 AWS 可观测性与成本分析的工具。

- **CloudWatch 指标**：查询指标时序数据（GetMetricData / GetMetricStatistics）
- **CloudWatch 告警**：获取当前告警状态与历史记录
- **CloudWatch Logs**：执行 Logs Insights 查询，检索应用日志
- **成本分析**：通过 Cost Explorer 获取费用趋势、预测与成本分解
- **成本优化**：通过 Cost Optimization Hub 获取优化建议与节省估算
