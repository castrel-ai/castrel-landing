## 概览

- **连接器名称**：`datadog`
- **支持的 API 版本**：Datadog REST API v1/v2
- **支持的服务端版本**：Datadog SaaS（所有区域）
- **官方文档**：[Datadog API Docs](https://docs.datadoghq.com/api/latest/)

## 配置

要使用 Datadog 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 用于标识该连接器实例的名称 |
| `base_url` | 是 | Datadog API 的基础 URL（例如 `https://api.datadoghq.com`） |
| `api_key` | 是 | 用于账号标识的 DD-API-KEY |
| `app_key` | 是 | 用于只读访问的 DD-APPLICATION-KEY |
| `verify_ssl` | 否 | 是否校验证书（默认：true） |

## 可用工具

该连接器提供用于日志、指标、监控器和事件探索的工具。

- **日志搜索**：使用查询语法搜索和聚合日志
- **指标查询**：查询时序数据、列出指标并获取元数据
- **监控器搜索**：搜索监控器并获取详情
- **事件搜索**：获取和搜索事件
