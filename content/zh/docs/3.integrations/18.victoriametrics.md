## 概览

- **连接器名称**：`victoriametrics`
- **支持的 API 版本**：VictoriaMetrics HTTP API（兼容 Prometheus API）
- **官方文档**：[VictoriaMetrics URL Examples](https://docs.victoriametrics.com/victoriametrics/url-examples/)

## 配置

要使用 VictoriaMetrics 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 是 | VictoriaMetrics 服务地址（例如 `http://victoriametrics:8428`） |
| `auth_type` | 否 | 认证方式：`none`（默认）、`basic` 或 `bearer` |
| `username` | 否 | Basic Auth 用户名（`auth_type=basic` 时使用） |
| `password` | 否 | Basic Auth 密码（`auth_type=basic` 时使用） |
| `token` | 否 | Bearer Token（`auth_type=bearer` 时使用） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`60`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供与 Prometheus 兼容的高性能指标查询工具。

- **即时查询**：执行 MetricsQL/PromQL 即时查询（`/api/v1/query`）
- **区间查询**：执行时间范围内的区间查询（`/api/v1/query_range`）
- **元数据发现**：列举指标名、标签名与标签值
- **时序搜索**：按标签选择器过滤时序数据
- **导出数据**：批量导出指标原始数据（`/api/v1/export`）
