## 概览

- **连接器名称**：`dingtalk_docs`
- **支持的 API 版本**：钉钉开放平台文档 API
- **官方文档**：[钉钉文档 API](https://open.dingtalk.com/document/orgapp/get-the-content-of-a-document)

## 配置

钉钉文档使用工作区级别的 OAuth 凭据访问，无需手动填写 Key/Secret。

在 Castrel 工作区中，点击「添加连接器」→「钉钉文档」，通过钉钉授权页面完成认证后即可使用。

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 连接器实例的展示名称（默认：`钉钉文档`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供钉钉文档的只读访问能力。

- **文档读取**：获取指定钉钉文档的正文内容
- **知识库搜索**：在钉钉知识库中检索文档
- **文档列举**：列出可访问的文档与目录结构
