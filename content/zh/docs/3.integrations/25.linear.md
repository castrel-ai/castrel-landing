## 概览

- **连接器名称**：`linear`
- **支持的 API 版本**：Linear GraphQL API v1
- **官方文档**：[Linear 开发者文档](https://developers.linear.app)

## 配置

要使用 Linear 工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `api_key` | 否 | Personal Access Token（从 Linear「Settings → API → Personal API Keys」中生成） |
| `access_token` | 否 | OAuth 2.0 Bearer Token（使用 OAuth 流程时填写） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`60`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> `api_key` 与 `access_token` 二选一。推荐使用 Personal API Key 进行快速接入。

## 可用工具

该连接器提供一整套 Linear 项目管理工具。

- **Issue 查询**：按 ID、状态、优先级、Assignee 过滤与查询 Issue
- **Issue 创建/更新**：创建新 Issue 或更新现有 Issue 状态与字段
- **项目管理**：查询项目列表、进度与关联 Issue
- **迭代（Cycle）**：获取当前迭代与历史迭代信息
- **团队管理**：查询团队成员、工作流状态与标签
