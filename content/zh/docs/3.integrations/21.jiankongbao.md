## 概览

- **连接器名称**：`jiankongbao`
- **支持的 API 版本**：监控宝 API v6
- **官方文档**：[监控宝帮助中心](https://help.cloudwise.com/help/38/41)

## 配置

要使用监控宝工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `base_url` | 否 | API 地址（默认：`https://v6-api.jiankongbao.com`） |
| `user_email` | 是 | 账户邮箱 |
| `user_pwd` | 是 | 密码的 MD5 值 |
| `client_id` | 是 | 授权 Client ID（商务提供） |
| `client_secret` | 是 | 授权 Client Secret（商务提供） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供一整套用于可用性监控数据查询的工具。

- **监控任务查询**：列举与查询监控任务列表和配置
- **可用性数据**：获取指定时间范围内的可用性指标
- **告警历史**：查询监控告警触发历史记录
- **性能数据**：获取响应时间、故障次数等性能指标
