## 概览

- **连接器名称**：`confluence`
- **支持的 API 版本**：Confluence Cloud REST API v2
- **官方文档**：[Confluence Cloud API 文档](https://developer.atlassian.com/cloud/confluence/)

## 配置

Confluence 使用 OAuth 2.0 授权流程，无需手动填写密钥。

在 Castrel 工作区中，点击「添加连接器」→「Confluence」→「Connect with Atlassian」，授权完成后即可使用。

| 字段 | 必填 | 说明 |
|------|------|------|
| `auth_type` | 是 | 固定为 `oauth2`，通过 Atlassian 授权页面完成认证 |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`60`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

> OAuth2 凭据由 Castrel 统一管理，token 自动刷新，无需手动维护。

## 可用工具

该连接器提供一整套用于 Confluence 知识库访问的工具。

- **内容搜索**：使用 CQL 语句全文检索 Confluence 页面与博文
- **页面读取**：获取指定页面的正文内容（Markdown / Storage 格式）
- **页面写入**：创建或更新 Confluence 页面
- **空间管理**：列举可访问的 Confluence 空间
- **RAG 数据抽取**：批量抽取页面内容用于知识库构建
