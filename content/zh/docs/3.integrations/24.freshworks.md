## 概览

- **连接器名称**：`freshworks`
- **支持的 API 版本**：Freshservice REST API v2
- **官方文档**：[Freshservice API 文档](https://api.freshservice.com/v2/#intro)

## 配置

Freshservice 使用 OAuth 2.0 授权流程，无需手动填写密钥。

在 Castrel 工作区中，点击「添加连接器」→「Freshservice」→「Connect with Freshworks」，授权完成后即可使用。

> OAuth2 凭据由 Castrel 统一管理，无需手动维护。

## 可用工具

该连接器提供 ITSM 全流程管理工具。

- **工单管理**：创建、查询、更新与关闭服务请求（Ticket）
- **问题管理**：查询与管理问题（Problem）记录
- **变更管理**：获取变更请求（Change）列表与详情
- **告警查询**：查看关联告警与对应工单
- **资产管理**：查询配置管理数据库（CMDB）资产信息
