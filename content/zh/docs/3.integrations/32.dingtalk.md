## 概览

- **连接器名称**：`dingtalk`
- **支持的 API 版本**：钉钉开放平台 API v1
- **官方文档**：[钉钉开放平台文档](https://open.dingtalk.com/document/dingstart/robot-receive-message)

## 配置

要使用钉钉工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `instance_name` | 是 | 连接器实例的展示名称 |
| `client_id` | 是 | 钉钉应用的 App Key（Client ID） |
| `client_secret` | 是 | 钉钉应用的 App Secret（Client Secret） |

> 在[钉钉开放平台](https://open-dev.dingtalk.com/)创建机器人应用后，即可获取 App Key 与 App Secret。

## 可用工具

该连接器提供钉钉消息通知与机器人交互能力。

- **消息发送**：向指定用户、群组或会话发送文本与富文本消息
- **消息接收**：接收用户发给机器人的消息并触发处理流程
- **群管理**：查询群成员与群信息
- **通知推送**：将告警、报告等内容推送到钉钉群或个人
