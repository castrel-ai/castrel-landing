## 概览

- **连接器名称**：`aliyun`
- **支持的 API 版本**：阿里云 OpenAPI（最新版）
- **官方文档**：[阿里云 OpenAPI](https://api.aliyun.com/api)

## 配置

要使用阿里云工具，你需要配置一个包含以下字段的 Connector：

| 字段 | 必填 | 说明 |
|------|------|------|
| `access_key_id` | 是 | 阿里云 AccessKey ID |
| `access_key_secret` | 是 | 阿里云 AccessKey Secret |
| `region` | 否 | 资源所在地域（默认：`cn-hangzhou`） |
| `security_token` | 否 | STS 临时凭证 Token（使用 STS 时填写） |
| `base_url` | 否 | API 基础地址（默认：`https://api.aliyun.com`） |
| `timeout` | 否 | 请求超时时间，单位秒（默认：`30`） |
| `verify_ssl` | 否 | 是否校验 SSL 证书（默认：`true`） |

## 可用工具

该连接器提供一整套用于阿里云资源访问与分析的工具。

- **日志查询**：通过 SLS（日志服务）检索与分析日志数据
- **指标监控**：从 ARMS/CMS 获取指标时序数据与告警状态
- **链路追踪**：查询 ARMS Tracing 请求链路数据
- **资源管理**：列举与查询云资源清单（ECS、RDS、OSS 等）
- **账单分析**：获取费用账单与成本优化建议
