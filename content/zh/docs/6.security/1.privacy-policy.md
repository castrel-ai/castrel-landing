## 1. 我们收集哪些信息？

**你向我们披露的个人信息**

***简而言之：** 我们会收集你主动提供给我们的个人信息。*

当你在服务上注册、表达对我们或我们的产品和服务的兴趣、参与服务中的活动，或以其他方式联系我们时，我们会收集你主动提供的个人信息。

**你提供的个人信息。** 我们收集的个人信息取决于你与我们及服务的互动场景、你的选择以及你使用的产品和功能。我们可能收集的个人信息包括：

- 电子邮箱地址
- 用户名

**敏感信息。** 我们不会处理敏感信息。

**支付数据。** 如果你选择进行购买，我们可能会收集处理付款所必需的数据，例如支付工具号码以及与该支付工具相关的安全码。所有支付数据均由 stripe 处理和存储。你可以在此查看其隐私政策：[https://stripe.com/en-sg/privacy](https://stripe.com/en-sg/privacy)。

**社交媒体登录数据。** 我们可能允许你使用现有社交媒体账号（如 Facebook、X 或其他社交账号）注册或登录。如果你选择这样做，我们会从相应社交媒体提供商处收集某些个人资料信息，详见下文“我们如何处理你的社交账号登录？”。

你向我们提供的所有个人信息都必须真实、完整且准确；如有变更，你应及时通知我们。

**自动收集的信息**

***简而言之：** 当你访问我们的服务时，我们会自动收集某些信息，例如你的 IP 地址以及浏览器和设备特征。*

当你访问、使用或浏览服务时，我们会自动收集某些信息。这些信息不会直接揭示你的具体身份（如姓名或联系方式），但可能包括设备与使用信息，例如 IP 地址、浏览器和设备特征、操作系统、语言偏好、引荐 URL、设备名称、国家/地区、位置、你使用服务的方式与时间，以及其他技术信息。这些信息主要用于维护服务的安全和正常运行，以及支持我们的内部分析与报表。

和许多企业一样，我们也会通过 Cookie 和类似技术收集信息。详情请见我们的 Cookie 声明：[http://www.castrel.ai/cookie-policy](http://www.castrel.ai/cookie-policy)。

我们收集的信息包括：

- *日志和使用数据。* 当你访问或使用服务时，我们的服务器会自动收集并记录服务相关、诊断、使用和性能信息。这些日志数据可能包括你的 IP 地址、设备信息、浏览器类型与设置，以及你在服务中的活动信息（例如使用时间、访问页面与文件、搜索以及功能使用情况），还包括设备事件信息（如系统活动、错误报告（有时称为“崩溃转储”）和硬件设置）。
- *设备数据。* 我们会收集你用于访问服务的计算机、手机、平板或其他设备的信息。根据设备不同，可能包括 IP 地址（或代理服务器）、设备与应用标识号、位置、浏览器类型、硬件型号、互联网服务提供商和/或移动运营商、操作系统以及系统配置信息。
- *位置数据。* 我们可能收集设备位置信息，包括精确或非精确位置。我们收集的信息量取决于你访问服务所使用设备的类型和设置。例如，我们可能使用 GPS 及其他技术来收集地理位置数据，从而获知你当前所在位置（基于你的 IP 地址）。你可以通过拒绝授权或关闭设备中的位置设置来阻止我们收集这些信息。但如果你选择退出，某些服务功能可能无法使用。

**Google API**

我们对通过 Google API 获取的信息的使用，将遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的 [Limited Use 要求](https://developers.google.com/terms/api-services-user-data-policy#limited-use)。

## 3. 我们处理你个人信息所依据的法律基础是什么？

***简而言之：** 我们仅会在认为有必要且根据适用法律具有合法依据的情况下处理你的个人信息，例如基于你的同意、为履行法律义务、为向你提供服务并履行合同义务、为保护你的权利，或为实现我们的合法商业利益。*

***如果你位于欧盟或英国，本节适用于你。***

《通用数据保护条例》（GDPR）和英国 GDPR 要求我们说明处理你个人信息时所依据的合法基础。因此，我们可能基于以下法律基础处理你的个人信息：

- **同意。** 如果你已授权（即同意）我们出于特定目的使用你的个人信息，我们可能会处理你的信息。你可以随时撤回同意。详见下文“撤回你的同意”。
- **合法利益。** 当我们认为为了实现我们的合法商业利益，处理你的信息是合理必要的，且你的利益及基本权利和自由并不优先于这些利益时，我们可能会处理你的信息。例如，我们可能出于以下目的处理你的个人信息：
  - 分析服务使用方式，以改进服务并提升用户留存
  - 诊断问题和/或预防欺诈行为
  - 了解用户如何使用我们的产品和服务，从而优化用户体验
- **法律义务。** 当我们认为有必要为遵守法律义务而处理你的信息时，例如配合法律执行机关或监管机构、行使或捍卫我们的合法权利，或在诉讼中将你的信息作为证据披露。
- **重大利益。** 当我们认为有必要保护你的重大利益或第三方重大利益时，我们可能会处理你的信息，例如涉及任何人生命安全威胁的情况。

***如果你位于加拿大，本节适用于你。***

如果你已明确授权（即明示同意）我们为某一特定目的使用你的个人信息，或在某些情形下可以推定你已同意（即默示同意），我们可能会处理你的信息。你可以随时 [撤回你的同意](#)。

在某些例外情况下，根据适用法律，我们可能被允许在未经你同意的情况下处理你的信息，例如：

- 如果收集显然符合某个人的利益，且无法及时取得同意
- 用于调查及欺诈检测与预防
- 用于满足特定条件的商业交易
- 如果信息载于证人陈述中，且收集该信息对于评估、处理或解决保险索赔是必要的
- 用于识别受伤、患病或死亡人员，并联系其近亲
- 如果我们有合理理由相信某个人曾经、正在或可能正在成为经济虐待的受害者
- 如果合理预期在征得同意后再收集和使用信息会影响信息的可得性或准确性，且该收集对于调查违约行为或违反加拿大或某省法律的情形而言是合理必要的
- 如果披露系为遵守传票、搜查令、法院命令或与提交记录相关的法院规则所必需
- 如果该信息是个人在其工作、业务或职业活动中产生，且收集目的与其产生目的相一致
- 如果收集仅用于新闻、艺术或文学目的
- 如果该信息已公开，且法规明确允许
- 在伦理监管与保密承诺前提下，我们可能会为经批准的研究或统计项目披露去标识化信息
