## Overview

- **Connector name**: `jenkins`
- **Supported API version**: Jenkins Remote Access API
- **Official docs**: [Jenkins Remote Access API](https://www.jenkins.io/doc/book/using/remote-access-api/)

## Configuration

To use Jenkins tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `base_url` | Yes | Jenkins server address (e.g., `http://jenkins.example.com`) |
| `username` | Yes | Jenkins username |
| `api_token` | Yes | Jenkins API Token (generated in user settings) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

> API Tokens can be generated in Jenkins under **User → Configure → API Token → Add new Token**.

## Available Tools

This connector provides a comprehensive set of tools for Jenkins CI/CD pipeline management.

- **Job queries**: List Jobs and retrieve Job details
- **Build history**: Query build records, status, and console output
- **Pipeline status**: Retrieve Pipeline stage execution status
- **Build triggering**: Remotely trigger Job builds with parameters
- **Queue queries**: View current build queue status
