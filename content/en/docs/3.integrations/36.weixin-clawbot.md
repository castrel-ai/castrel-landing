## Overview

- **Connector name**: `weixin_clawbot`
- **Supported API version**: Enterprise WeChat API v3
- **Official docs**: [Enterprise WeChat Developer Docs](https://developer.work.weixin.qq.com/document/path/90664)

## Configuration

To use Enterprise WeChat tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `instance_name` | Yes | Display name for this connector instance |
| `token` | Yes | Enterprise WeChat application Access Token or Bot Webhook Token |
| `user_id` | Yes | Default recipient user ID or group ID |

## Available Tools

This connector provides Enterprise WeChat message sending and notification capabilities.

- **Message sending**: Send text messages to specified users, departments, or tag groups
- **Markdown messages**: Send rich-text notifications in Markdown format
- **Alert push**: Push monitoring alerts and reports to Enterprise WeChat
- **Graphic messages**: Send image-text card messages
