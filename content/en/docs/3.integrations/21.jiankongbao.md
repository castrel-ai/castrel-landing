## Overview

- **Connector name**: `jiankongbao`
- **Supported API version**: JianKongBao API v6
- **Official docs**: [JianKongBao Help Center](https://help.cloudwise.com/help/38/41)

## Configuration

To use JianKongBao tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `user_email` | Yes | Account email address |
| `user_pwd` | Yes | MD5 hash of account password |
| `client_id` | Yes | Authorized Client ID (provided by the vendor) |
| `client_secret` | Yes | Authorized Client Secret (provided by the vendor) |
| `base_url` | No | API address (default: `https://v6-api.jiankongbao.com`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides a comprehensive set of availability monitoring data query tools.

- **Monitor task queries**: List and query monitor task lists and configurations
- **Availability data**: Retrieve availability metrics for a specified time range
- **Alert history**: Query triggered monitoring alert history records
- **Performance data**: Retrieve response times, failure counts, and other performance metrics
