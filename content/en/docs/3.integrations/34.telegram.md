## Overview

- **Connector name**: `telegram`
- **Supported API version**: Telegram Bot API
- **Official docs**: [Telegram Bot API Documentation](https://core.telegram.org/bots/api)

## Configuration

To use Telegram tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `instance_name` | Yes | Display name for this connector instance |
| `token` | Yes | Telegram Bot Token (obtained by creating a bot via [@BotFather](https://t.me/BotFather)) |

> Bot Token format: `{bot_id}:{secret}`, e.g., `1234567890:AAxxxxxx`.

## Available Tools

This connector provides Telegram bot message sending and notification capabilities.

- **Message sending**: Send text messages to specified Chat IDs (users, groups, or channels)
- **Markdown messages**: Send rich-text notifications supporting Markdown formatting
- **Alert push**: Push monitoring alerts and reports to Telegram groups or individuals
- **File sending**: Send document and image attachments
