## Overview

- **Connector name**: `volcengine`
- **Supported API version**: Volcengine OpenAPI (latest)
- **Official docs**: [Volcengine API Documentation](https://api.volcengine.com/api-docs)

## Configuration

To use Volcengine tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `access_key_id` | Yes | Access Key ID |
| `secret_access_key` | Yes | Secret Access Key |
| `region` | Yes | Region identifier (e.g., `cn-beijing`, `ap-southeast-1`) |
| `session_token` | No | Temporary credential Session Token (required when using STS) |
| `base_url` | No | API base URL (default: `https://open.volcengineapi.com`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |
| `service_versions` | No | API version overrides for each service (e.g., ECS, CloudMonitor, TLS) |

## Available Tools

This connector provides a comprehensive set of read-only Volcengine tools.

- **TLS log queries**: Search application and system logs in Volcengine Log Service (TLS)
- **CloudMonitor metrics**: Retrieve cloud monitoring metric time-series data
- **Alert queries**: Retrieve currently active alerts and history
- **APM tracing**: Query distributed trace data
- **ECS resource inventory**: List and query ECS instance information
- **Billing analysis**: Retrieve billing details and cost data
