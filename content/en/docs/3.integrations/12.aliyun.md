## Overview

- **Connector name**: `aliyun`
- **Supported API version**: Alibaba Cloud OpenAPI (latest)
- **Official docs**: [Alibaba Cloud OpenAPI](https://api.aliyun.com/api)

## Configuration

To use Alibaba Cloud tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `access_key_id` | Yes | Alibaba Cloud AccessKey ID |
| `access_key_secret` | Yes | Alibaba Cloud AccessKey Secret |
| `region` | No | Resource region (default: `cn-hangzhou`) |
| `security_token` | No | STS temporary credential token (required when using STS) |
| `base_url` | No | API base URL (default: `https://api.aliyun.com`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides a comprehensive set of tools for Alibaba Cloud resource access and analysis.

- **Log queries**: Search and analyze logs via SLS (Log Service)
- **Metrics monitoring**: Retrieve metric time-series data and alert status from ARMS/CMS
- **Distributed tracing**: Query ARMS Tracing request trace data
- **Resource management**: List and query cloud resource inventories (ECS, RDS, OSS, etc.)
- **Billing analysis**: Retrieve billing details and cost optimization recommendations
