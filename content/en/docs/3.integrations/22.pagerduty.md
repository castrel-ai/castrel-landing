## Overview

- **Connector name**: `pagerduty`
- **Supported API version**: PagerDuty REST API v2
- **Official docs**: [PagerDuty API Reference](https://developer.pagerduty.com/api-reference/)

## Configuration

To use PagerDuty tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `api_token` | Yes | PagerDuty API Token (create at **User Settings → API Access → Create New API Key**) |
| `from_email` | No | Email address used as the `From` header in write operations (acknowledge/resolve/add note) |
| `base_url` | No | API base URL (default: `https://api.pagerduty.com`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides a comprehensive set of PagerDuty incident management and SRE automation tools.

- **Incident management**: Query, acknowledge, resolve Incidents, and add notes
- **Alert queries**: Retrieve alert lists and details
- **On-call queries**: View current on-call personnel and on-call schedules
- **Service management**: List services, integrations, and upstream dependencies
- **Log entries**: Retrieve Incident log entries and event timelines
