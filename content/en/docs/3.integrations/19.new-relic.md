## Overview

- **Connector name**: `new_relic`
- **Supported API version**: New Relic REST API v2, NerdGraph (GraphQL)
- **Official docs**: [New Relic REST API v2](https://docs.newrelic.com/docs/apis/rest-api-v2/get-started/introduction-new-relic-rest-api-v2/)

## Configuration

To use New Relic tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `api_key` | Yes | New Relic User API Key |
| `account_id` | No | Default account ID (used for NRQL queries) |
| `region` | No | Region: `US` (default) or `EU` |
| `base_url` | No | API base URL (US: `https://api.newrelic.com`; EU: `https://api.eu.newrelic.com`) |
| `graphql_url` | No | NerdGraph endpoint (default: `https://api.newrelic.com/graphql`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

> User API Keys can be created in New Relic under **User menu → API keys**.

## Available Tools

This connector provides a comprehensive set of New Relic full-stack observability data query tools.

- **APM queries**: Retrieve application performance metrics, transactions, and error rates
- **Log retrieval**: Full-text search in New Relic Logs
- **NRQL queries**: Execute New Relic Query Language (NRQL) for custom analysis
- **Distributed tracing**: Query distributed trace data
- **Infrastructure**: Retrieve host, K8s cluster, and cloud integration status
- **Alert management**: Query alert policies, conditions, and Incident records
- **Dashboard queries**: Retrieve Dashboard lists and chart data
- **Synthetic monitoring**: Query Synthetic monitor execution results
