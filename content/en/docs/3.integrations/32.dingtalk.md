## Overview

- **Connector name**: `dingtalk`
- **Supported API version**: DingTalk Open Platform API v1
- **Official docs**: [DingTalk Open Platform Docs](https://open.dingtalk.com/document/dingstart/robot-receive-message)

## Configuration

To use DingTalk tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `instance_name` | Yes | Display name for this connector instance |
| `client_id` | Yes | DingTalk application App Key (Client ID) |
| `client_secret` | Yes | DingTalk application App Secret (Client Secret) |

> After creating a bot application on the [DingTalk Open Platform](https://open-dev.dingtalk.com/), you can obtain the App Key and App Secret.

## Available Tools

This connector provides DingTalk messaging and bot interaction capabilities.

- **Message sending**: Send text and rich-text messages to specified users, groups, or conversations
- **Message receiving**: Receive messages sent by users to the bot and trigger processing flows
- **Group management**: Query group members and group information
- **Notification push**: Push alerts and reports to DingTalk groups or individuals
