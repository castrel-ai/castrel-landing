## Overview

- **Connector name**: `sentry`
- **Supported API version**: Sentry REST API v0
- **Official docs**: [Sentry API Documentation](https://docs.sentry.io/api/)

## Configuration

To use Sentry tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `bearer_token` | Yes | Sentry Auth Token (create at **Settings → Account → API Tokens**) |
| `base_url` | No | API base URL (default: `https://sentry.io`; enter custom address for self-hosted) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides a comprehensive set of Sentry error monitoring and performance analysis tools.

- **Organizations & Projects**: List organizations, project configurations, and team information
- **Issue queries**: Search Error Issues by status, priority, and time range
- **Event retrieval**: Retrieve error event details and stack traces associated with an Issue
- **Time-series statistics**: Retrieve time-series aggregated data for error rates and event counts
- **Alert rules**: Query alert rules and notification configurations
