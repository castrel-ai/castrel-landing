## Overview

- **Connector name**: `email`
- **Protocol**: SMTP / RFC 5322
- **Official docs**: [RFC 5322 Internet Message Format](https://www.rfc-editor.org/rfc/rfc5322)

## Configuration

To use Email tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `instance_name` | Yes | Display name for this connector instance |
| `address` | Yes | Sender email address (e.g., `alerts@example.com`) |

## Available Tools

This connector provides email notification delivery capabilities.

- **Email sending**: Send plain text or HTML emails to specified recipients
- **Alert notifications**: Push system alerts and reports via email
- **Bulk sending**: Send emails to multiple recipients in a single operation
