## Overview

- **Connector name**: `tencent_cloud`
- **Supported API version**: Tencent Cloud CAM API (latest)
- **Official docs**: [Tencent Cloud API Documentation](https://cloud.tencent.com/document/api)

## Configuration

To use Tencent Cloud tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `secret_id` | Yes | CAM SecretId (create in **Access Management → API Key Management**) |
| `secret_key` | Yes | CAM SecretKey |
| `region` | Yes | Region identifier (e.g., `ap-guangzhou`, `ap-beijing`) |
| `token` | No | Temporary credential Token (required when using STS roles) |
| `base_url` | No | API base URL (default: `https://tencentcloudapi.com`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

> It is recommended to create a read-only sub-account and grant policies such as `QcloudMonitorReadOnlyAccess` and `QcloudCLSReadOnlyAccess`.

## Available Tools

This connector provides a comprehensive set of read-only Tencent Cloud tools.

- **Cloud Monitor (CM)**: Query metric data and alert history
- **Log Service (CLS)**: Search and analyze log data
- **Cloud resource discovery**: List CVM, RDS, TKE, and other resource inventories
- **Billing analysis**: Retrieve billing details and cost data
