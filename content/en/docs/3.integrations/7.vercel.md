## Overview

- **Connector name**: `vercel`
- **Protocol**: Model Context Protocol (MCP)
- **Official docs**: [Vercel API Documentation](https://vercel.com/docs/rest-api)

## Configuration

Vercel uses the OAuth 2.0 authorization flow — no manual key entry required.

In your Castrel workspace, click **Add Connector → Vercel → Connect with Vercel** and complete the authorization.

> OAuth2 credentials are managed centrally by Castrel. Permission scope covers the Vercel teams and projects you authorize.

## Available Tools

This connector provides Vercel project and deployment management capabilities via the MCP protocol.

- **Project queries**: List projects and configurations within a team
- **Deployment queries**: Retrieve deployment history, status, and build logs
- **Function logs**: Retrieve Serverless Function / Edge Function runtime logs
- **Domain management**: Query domain bindings and DNS configurations
- **Environment variables**: View project environment variable names (values are masked)
