## Overview

- **Connector name**: `ldap`
- **Supported protocols**: LDAP v3 (RFC 4511), LDAPS
- **Official docs**: [RFC 4511 - Lightweight Directory Access Protocol](https://datatracker.ietf.org/doc/html/rfc4511)

## Configuration

To use LDAP tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `base_url` | Yes | LDAP server address (e.g., `ldap://ldap.example.com:389` or `ldaps://ldap.example.com:636`) |
| `bind_dn` | Yes | Bind user DN (e.g., `cn=admin,dc=example,dc=com`) |
| `bind_password` | Yes | Bind user password |
| `search_base` | No | Search base DN (e.g., `dc=example,dc=com`); auto-detected from server if left blank |
| `timeout` | No | Connection timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (effective for LDAPS, default: `true`) |

## Available Tools

This connector provides a comprehensive set of LDAP directory service query tools.

- **User search**: Search users by uid, email, name, and other attributes
- **User details**: Retrieve complete attribute information for a specified user
- **Group queries**: List and query user groups and their members
- **OU queries**: Browse organizational unit (OU) hierarchies
- **Group membership**: Query all groups a specified user belongs to
