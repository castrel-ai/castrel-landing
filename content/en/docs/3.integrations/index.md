Castrel supports integrations across observability, collaboration, and delivery workflows.

## Available Integrations

- [Prometheus](/docs/integrations/prometheus)
- [Elasticsearch](/docs/integrations/elasticsearch)
- [Grafana Loki](/docs/integrations/grafana-loki)
- [Grafana Tempo](/docs/integrations/grafana-tempo)
- [GitHub](/docs/integrations/github)
- [Slack](/docs/integrations/slack)
- [Vercel](/docs/integrations/vercel)
- [Graylog](/docs/integrations/graylog)
- [Datadog](/docs/integrations/datadog)

## Quick Start

1. Open **Integrations** in Castrel.
2. Select the tool you want to connect.
3. Authorize read access and finish the setup flow.
4. Run a feature task (Alert Triage / Incident Investigation / Deployment Verification) to verify data is available.
