## Overview

- **Connector name**: `feishu`
- **Supported API version**: Feishu Open Platform API v3
- **Official docs**: [Feishu Open Platform Documentation](https://open.feishu.cn/document/home/index)

## Configuration

To use Feishu tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `instance_name` | Yes | Display name for this connector instance |
| `app_id` | Yes | Feishu application App ID |
| `app_secret` | Yes | Feishu application App Secret |

> After creating a custom application on the [Feishu Open Platform](https://open.feishu.cn/), you can obtain the App ID and App Secret.

## Available Tools

This connector provides Feishu messaging and bot interaction capabilities.

- **Message sending**: Send text and card messages to specified users, groups, or conversations
- **Message receiving**: Receive messages sent by users to the bot and trigger processing flows
- **User queries**: Look up Feishu user information by email or phone number
- **Group management**: Query group members and group information
- **Notification push**: Push alerts and reports to Feishu groups or individuals
