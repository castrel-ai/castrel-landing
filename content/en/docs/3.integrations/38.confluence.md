## Overview

- **Connector name**: `confluence`
- **Supported API version**: Confluence Cloud REST API v2
- **Official docs**: [Confluence Cloud API Docs](https://developer.atlassian.com/cloud/confluence/)

## Configuration

Confluence uses the OAuth 2.0 authorization flow — no manual key entry required.

In your Castrel workspace, click **Add Connector → Confluence → Connect with Atlassian** and complete the authorization.

| Field | Required | Description |
|-------|----------|-------------|
| `auth_type` | Yes | Fixed as `oauth2`; authentication is completed via the Atlassian authorization page |
| `timeout` | No | Request timeout in seconds (default: `60`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

> OAuth2 credentials are managed centrally by Castrel with automatic token refresh — no manual maintenance needed.

## Available Tools

This connector provides a comprehensive set of tools for Confluence knowledge base access.

- **Content search**: Full-text search of Confluence pages and blog posts using CQL
- **Page reading**: Retrieve page body content (Markdown / Storage format)
- **Page writing**: Create or update Confluence pages
- **Space management**: List accessible Confluence spaces
- **RAG data extraction**: Batch-extract page content for knowledge base construction
