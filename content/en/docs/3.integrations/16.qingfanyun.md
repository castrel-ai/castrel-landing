## Overview

- **Connector name**: `qingfanyun`
- **Supported API version**: QingFanYun ITSM API v1
- **Official docs**: [Cloudwise Website](https://www.cloudwise.com)

## Configuration

To use QingFanYun tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `base_url` | Yes | API base URL (e.g., `https://itsm.cloudwise.com/docp/gatewayApi/dosm`) |
| `account_id` | Yes | Secondary tenant ID |
| `top_account_id` | Yes | Top-level tenant ID (same as `account_id` when no sub-tenants exist) |
| `user_id` | Yes | User ID |
| `app_key` | Yes | Application Key |
| `app_secret` | Yes | Application Secret |
| `auth_type` | No | Authentication type (default: `secret`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides full QingFanYun ITSM ticket lifecycle management tools.

- **Process template queries**: List available ticket process templates
- **Ticket creation**: Create new tickets from process templates
- **Ticket queries**: Search tickets by ID, status, and time range
- **Ticket updates**: Update ticket fields and status
- **Ticket workflow**: Submit, reassign, and close tickets
