## Overview

- **Connector name**: `notion`
- **Protocol**: Model Context Protocol (MCP)
- **Official docs**: [Notion API Documentation](https://developers.notion.com/)

## Configuration

Notion uses the OAuth 2.0 authorization flow — no manual key entry required.

In your Castrel workspace, click **Add Connector → Notion → Connect with Notion**, complete the authorization, and select the pages and databases you want to allow access to.

> OAuth2 credentials are managed centrally by Castrel. Authorization scope is limited to the pages and databases you explicitly select.

## Available Tools

This connector provides Notion knowledge base access capabilities via the MCP protocol.

- **Page search**: Full-text search of pages and content in the Notion workspace
- **Page reading**: Retrieve the body content of specified pages (Markdown format)
- **Page create/update**: Create new pages or update existing page content
- **Database queries**: Filter, sort, and query Notion database records
- **Database record operations**: Add or update records in a database
