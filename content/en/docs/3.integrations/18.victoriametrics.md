## Overview

- **Connector name**: `victoriametrics`
- **Supported API version**: VictoriaMetrics HTTP API (Prometheus API compatible)
- **Official docs**: [VictoriaMetrics URL Examples](https://docs.victoriametrics.com/victoriametrics/url-examples/)

## Configuration

To use VictoriaMetrics tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `base_url` | Yes | VictoriaMetrics service address (e.g., `http://victoriametrics:8428`) |
| `auth_type` | No | Authentication type: `none` (default), `basic`, or `bearer` |
| `username` | No | Basic Auth username (used when `auth_type=basic`) |
| `password` | No | Basic Auth password (used when `auth_type=basic`) |
| `token` | No | Bearer Token (used when `auth_type=bearer`) |
| `timeout` | No | Request timeout in seconds (default: `60`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides high-performance metrics querying tools compatible with Prometheus.

- **Instant queries**: Execute MetricsQL/PromQL instant queries (`/api/v1/query`)
- **Range queries**: Execute range queries over a time window (`/api/v1/query_range`)
- **Metadata discovery**: List metric names, label names, and label values
- **Time series search**: Filter time series by label selectors
- **Data export**: Batch-export raw metric data (`/api/v1/export`)
