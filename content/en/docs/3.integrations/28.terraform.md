## Overview

- **Connector name**: `terraform`
- **Supported API version**: HCP Terraform REST API v2
- **Official docs**: [HCP Terraform API Documentation](https://developer.hashicorp.com/terraform/cloud-docs/api-docs)

## Configuration

To use Terraform tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `api_token` | Yes | API Token (User/Team/Organization Token; create in HCP Terraform under **User Settings → Tokens**) |
| `auth_type` | No | Authentication type, fixed as `bearer` (default) |
| `base_url` | No | API base URL (default: `https://app.terraform.io/api/v2`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides a comprehensive set of Terraform Cloud infrastructure-as-code management tools.

- **Workspace queries**: List workspaces and configurations within an organization
- **Run management**: Retrieve workspace Run history, plan output, and apply status
- **State queries**: Retrieve current State file content and resource lists
- **Variable queries**: List workspace variables (values are masked)
- **Cost estimation**: Retrieve cost estimation results for Runs (requires feature to be enabled)
