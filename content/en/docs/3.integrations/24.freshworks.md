## Overview

- **Connector name**: `freshworks`
- **Supported API version**: Freshservice REST API v2
- **Official docs**: [Freshservice API Documentation](https://api.freshservice.com/v2/#intro)

## Configuration

Freshservice uses the OAuth 2.0 authorization flow — no manual key entry required.

In your Castrel workspace, click **Add Connector → Freshservice → Connect with Freshworks** and complete the authorization.

> OAuth2 credentials are managed centrally by Castrel — no manual maintenance needed.

## Available Tools

This connector provides full ITSM lifecycle management tools.

- **Ticket management**: Create, query, update, and close service requests (Tickets)
- **Problem management**: Query and manage Problem records
- **Change management**: Retrieve Change Request lists and details
- **Alert queries**: View associated alerts and corresponding tickets
- **Asset management**: Query CMDB (Configuration Management Database) asset information
