## Overview

- **Connector name**: `huaweicloud`
- **Supported API version**: Huawei Cloud OpenAPI (latest)
- **Official docs**: [Huawei Cloud API Explorer](https://console.huaweicloud.com/apiexplorer)

## Configuration

To use Huawei Cloud tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `access_key_id` | Yes | AK (Access Key ID) |
| `secret_access_key` | Yes | SK (Secret Access Key) |
| `region` | Yes | Region identifier (e.g., `cn-north-4`) |
| `project_id` | Yes | Project ID |
| `domain_id` | No | Account ID (required for cross-project queries) |
| `enterprise_project_id` | No | Enterprise project ID (default: `all_granted_eps`) |
| `apm_business_id` | No | APM business ID |
| `language` | No | Response language (default: `zh_cn`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |
| `service_endpoints` | No | Custom endpoints for each service (for private or dedicated cloud scenarios) |

## Available Tools

This connector provides a comprehensive set of read-only Huawei Cloud tools.

- **LTS log queries**: Search application and system logs in Huawei Cloud Log Tank Service (LTS)
- **CES metrics**: Retrieve Cloud Eye (CES) metric time-series data
- **CES alerts**: Retrieve currently active alerts and alert history
- **APM tracing**: Query application trace and performance analysis data
- **RMS resource inventory**: List and query cloud resources (ECS, RDS, VPC, etc.)
- **BSS billing analysis**: Retrieve billing details and cost analysis data
