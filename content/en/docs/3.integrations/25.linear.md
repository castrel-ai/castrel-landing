## Overview

- **Connector name**: `linear`
- **Supported API version**: Linear GraphQL API v1
- **Official docs**: [Linear Developer Documentation](https://developers.linear.app)

## Configuration

To use Linear tools, create a Connector with the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| `api_key` | No | Personal Access Token (generated in Linear under **Settings → API → Personal API Keys**) |
| `access_token` | No | OAuth 2.0 Bearer Token (used when following the OAuth flow) |
| `timeout` | No | Request timeout in seconds (default: `60`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

> Choose either `api_key` or `access_token`. A Personal API Key is recommended for quick setup.

## Available Tools

This connector provides a comprehensive set of Linear project management tools.

- **Issue queries**: Filter and query Issues by ID, status, priority, and assignee
- **Issue create/update**: Create new Issues or update existing Issue status and fields
- **Project management**: Query project lists, progress, and associated Issues
- **Cycles**: Retrieve current and historical Cycle information
- **Team management**: Query team members, workflow states, and labels
