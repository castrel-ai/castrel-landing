## Overview

- **Connector name**: `dingtalk_docs`
- **Supported API version**: DingTalk Open Platform Docs API
- **Official docs**: [DingTalk Docs API](https://open.dingtalk.com/document/orgapp/get-the-content-of-a-document)

## Configuration

DingTalk Docs uses workspace-level OAuth credentials — no manual key/secret entry required.

In your Castrel workspace, click **Add Connector → DingTalk Docs** and complete authorization through the DingTalk authorization page.

| Field | Required | Description |
|-------|----------|-------------|
| `instance_name` | Yes | Display name for this connector instance (default: `DingTalk Docs`) |
| `timeout` | No | Request timeout in seconds (default: `30`) |
| `verify_ssl` | No | Verify SSL certificates (default: `true`) |

## Available Tools

This connector provides read-only access to DingTalk Docs.

- **Document reading**: Retrieve the body content of specified DingTalk documents
- **Knowledge base search**: Search documents within DingTalk knowledge bases
- **Document listing**: List accessible documents and directory structures
