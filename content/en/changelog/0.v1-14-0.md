## New Feature: Agent Run Permission Policies

When starting a conversation, you can choose a permission policy for the Agent run, giving you precise control over the scope of actions the Agent can perform and balancing safety with efficiency in automated operations.

Four levels are available: **Read-only** prevents the Agent from writing to external systems through Connectors or Castrel Proxy nodes, while actions inside Castrel such as saving findings or writing to the knowledge base remain available; **Request Approval** asks for your confirmation before every outbound write; **Approve for Me** lets the AI approve routine actions on your behalf, stopping to request your confirmation only for risky operations; and **Full Access** requires no manual approval, suited for fully trusted automation scenarios.

## New Feature: Theme Switching & Appearance Persistence

Castrel now supports theme switching — you can move freely between dark and light themes and adjust the font size for both the interface and the chat area. Chat, task details, sub-agent views, the document workspace, and terminal output all follow your settings consistently, keeping readability and visual style aligned across views under any theme.

Appearance settings are now account-level persistent configuration. After login, your preferences load from the server first and save automatically when changed, so they are restored on page refresh, re-login, or device switch — no longer tied to a single browser. When you are signed out or the server is unavailable, the interface falls back to local settings to stay usable. Theme actions in the settings panel now use a unified save and cancel in the header.
