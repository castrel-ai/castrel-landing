## New Feature: Incident Studio

The all-new Incident Studio module is now live, providing a dedicated workspace for event-driven investigation and collaboration workflows.

- **Studio-based task management:** Tasks can now be assigned to a specific Studio at creation time, orthogonal to Application, current mode, and trigger mode — enabling finer-grained task ownership and context isolation.
- **Focused incident investigation:** Incident Studio offers an event-centric investigation view, aggregating alerts, logs, and change events into a unified incident timeline to help teams rapidly identify root causes.

## New Feature: Application Module Overhaul

The Application module has been comprehensively redesigned around core user journeys, with new health inspection capabilities:

- **User journey redesign:** Restructured the Application module's core entry points, key nodes, and state transitions. Optimized information architecture and interaction paths to reduce friction.
- **Health inspection:** Create and execute health inspection tasks directly from the application page, with a 30-day health status trend display. Added a dedicated health inspection mode in the new task page — after execution, one-click automation creation and binding to the current application is supported.
