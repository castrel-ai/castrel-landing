## Full Release Checklist

### feat

- Added automatic Canvas panel display of Knowledge details after get_knowledge tool invocation in Chat.
- Added connector data query result visualization in Chat sessions.
- Optimized Proxy MCP tool execution with persistent connections and stdio mode support, eliminating per-invocation connection overhead.
- Added Docker-based Proxy deployment with built-in MCP runtime environment; improved ComputerMcp dispatch logic and added UI markers for readonly MCP tools.

### bugfix

- Fixed an issue where integration sort order jumped to the top after installation.
- Fixed an issue where viewing shared data exploration tasks incorrectly required login.
- Fixed an issue where communication tool integrations were mislabeled as "Connector" instead of "Collaboration Tool".
