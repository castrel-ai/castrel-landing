## Full Release Checklist

### feat

- Upgraded the /SLO command to generate an observability dashboard in one click.
- Optimized session context building to improve chat and root cause analysis (RCA) stability.
- Enhanced Skill invocation so it can directly read all guidance documents under a Skill.

### bugfix

- Fixed an issue where scheduled automation messages split the content and AI instructions apart, then merged them again after a reply.
- Fixed a display issue where task content and instructions in automation trigger messages were laid out together.
- Fixed an occasional error when entering inspection mode during health checks, along with an incorrect general chat status.
