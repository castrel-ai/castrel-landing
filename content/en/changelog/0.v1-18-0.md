## New Feature: Unified Loop & Automation

We have merged the previously separate loop tasks and automation into a single automation system. Creation, editing, and triggering now share one unified entry point, so there is no longer a need to reason about two sets of logic.

Automation tasks now support two run modes. You can bind a task to a session so that scheduled or event-driven triggers continue the conversation within that same session, or run it as an independent task that starts a fresh session on every trigger. When a session-bound task fires, newly generated messages render in real time so progress is clear at a glance.

The editor lets you pick the session to bind directly, with a dropdown that merges and de-duplicates the current session and your favorited sessions. Once session-bound mode is selected, unrelated settings such as notification channels are automatically hidden, keeping automation configuration focused.

## 4 Enhanced Connector Best Practices

This release adds best-practice Skills for commonly used observability and operations connectors, making intelligent diagnostics more reliable and closer to real-world usage:

- **Datadog:** Improved practices for querying and diagnosing metrics, logs, and monitoring data.
- **Kubernetes:** Optimized recommendations for cluster resources, workloads, and event troubleshooting.
- **Helm:** Added best practices for release management and deployment troubleshooting.
- **Docker:** Improved diagnostic usage for containers and images.
