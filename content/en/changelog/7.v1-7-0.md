## New Feature: Demo Workspace One-Click Experience

This update introduces the Demo Workspace guided experience on the `New Task` page, enabling new users to get started instantly with zero configuration. A persistent "Try Castrel Demo" banner at the bottom of the page lets you jump into the pre-configured Demo Workspace in one click.

Once inside, you can trigger the @ menu directly from the overview cards. Combined with fully optimized scenario-based recommended prompts, you can start asking questions against real example objects and experience the core workflow seamlessly.

## Enhancement: Precise @Connector Object Reference

This release also enhances the @ mention capability, supporting precise references to underlying Connector objects in conversations — including Prometheus, ClickHouse, Elasticsearch, Grafana, Tempo, Loki, GitHub, GitLab, and more. Together with Context support for Connector internal object operations, this capability comprehensively covers and accelerates diagnostic efficiency in troubleshooting and alert analysis scenarios.
