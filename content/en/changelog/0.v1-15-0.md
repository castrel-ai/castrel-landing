## New Feature: Ops Slash Commands

Type a slash in the chat input to call a set of ops commands and handle deployment and checks right inside the conversation. `/deploy` reads an application's deployment guide, drafts a rollout plan, and kicks off the deployment; `/health` runs a health check against your SLO docs across one or more applications and returns a clear status.

`/loop` runs a task on a set interval, and `/goal` sets the objective for the conversation. Each command comes with inline hints and a target-application picker, so you follow the prompts to fill in the parameters and run.
