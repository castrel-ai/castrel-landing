## New Feature: Ops Slash Commands

Type a slash in the chat input to start deployments, run checks, and keep watch over your systems — no switching tools or memorizing complex commands. This release adds four commands — `/deploy`, `/health`, `/loop`, and `/goal` — covering everything from one-off actions to ongoing monitoring.

`/deploy` and `/health` both run against an application you pick, and both treat the docs in that application's knowledge base as the single source of truth, so the Agent follows your established rules instead of inventing steps. With `/deploy <application>`, the Agent reads the deployment doc, runs the rollout exactly as documented, and reports back the deploy link, pipeline ID, and any errors with next steps. `/health` gathers monitoring signals based on your SLO doc and returns a structured health report — overall status, per-SLO compliance, error-budget burn, active anomalies, root-cause hints, and suggested actions — so you can see at a glance whether an application is healthy.

`/loop` turns any command or prompt into a recurring task — for example, `/loop 5m /health payment-service` checks the payment service every five minutes. It runs once right away, repeats on the interval you set, stops automatically after seven days, and can be cancelled anytime, making it ideal for watching deploy status or alerts.

`/goal` sets a completion condition for the conversation, such as "resolve all 503 errors." Once set, the Agent gets to work and keeps evaluating progress, ending the conversation automatically when the goal is met — no manual wrap-up needed. Type `/goal clear` to remove it at any time.
