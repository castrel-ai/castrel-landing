## Full Release Checklist

### bugfix

- Fixed an issue where the Google Docs integration returned an error during authorization and could not connect.
- Fixed an issue where all Notion integration tool calls failed.
- Fixed an issue where Notion and DingTalk Docs redirected to the plugin list instead of their own detail page after installation.
- Fixed a misaligned layout on the Vercel integration events page and tool call failures for Vercel integrations connected earlier.
