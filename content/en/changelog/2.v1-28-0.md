## Enhanced: Evidence References, Unified and Traceable

When AI cites the result of a tool call — a metrics chart, a log query — as supporting evidence, that reference now shows the same content and behaves the same way wherever you click it: in a chat message, an expanded report, or the right panel.

References in knowledge base articles, incident reports, and notifications pushed through IM channels like Lark are also directly clickable and take you to the same evidence.

## Full Release Checklist

### feat

- Unified the display and interaction of tool-call evidence references across chat, reports, and the right panel.
- Aligned the app management dialog style with the personal access token page.
- Refactored alert detail components and data migration logic for improved stability.

### bugfix

- Fixed a permission error when integrating Lark documents via QR code; required permissions are now configured automatically after the app is created.
- Fixed Lark knowledge base queries returning an empty list; added knowledge spaces are now returned correctly.
- Removed a Lark knowledge base node query tool with a parameter validation defect that caused errors.
- Fixed a missing save button on the "replace app link" configuration page in Lark document integration, which prevented changes from taking effect.
- Fixed the download button remaining clickable while a chart was still loading; it's now disabled until loading completes.
- Fixed the topology graph not refreshing automatically after saving and exiting, requiring a manual refresh to see the latest topology.
- Fixed an occasional redirect to the new task page for regular users visiting app management.
- Fixed the download button not being disabled during document export, which could allow duplicate downloads.
