## New Feature: /SLO Command Generates Dashboards

This release extends the `/SLO` command from generating SLO documents to generating an observability dashboard in one click. Type `/SLO` in an analysis session and Castrel automatically orchestrates and builds the corresponding dashboard based on the target service's golden signals and SLO definitions, giving you a unified observability view during troubleshooting and inspections.

The generated dashboard surfaces key metric trends and SLO attainment directly, reducing the effort of building panels by hand and closing the loop from SLO definition to visualization.
