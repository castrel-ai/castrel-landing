## Full Release Checklist

### feat

- Added task archive and deletion with quick sidebar operations and archived task restoration management.
- Introduced main interaction channel and multi-notification channel mechanism for flexible message routing.
- Redesigned SubAgent conversation list with a tree-view UI to clearly present hierarchical call relationships.
- Added Email column display to the workspace member list page.
- Optimized system prompts to improve Agent response accuracy and consistency.
- Improved Banner popup interaction and visual experience.
- Restructured registration and login page to use tab switching instead of stacking multiple auth methods.
- Added Tencent BlueKing Connector integration.
- Added Wangsu SD-WAN Connector integration.

### bugfix

- Fixed an issue where Map-type fields in Connectors did not properly handle JSON strings (affecting ES, Kubernetes, and QingfanYun).
- Fixed an issue where selecting WPS as the automation notification channel prevented adding Lark or multiple WPS groups.
- Fixed an issue where replies from the WPS notification channel were not routed to the automation conversation.
- Fixed an error that occurred when continuing a conversation after generating a troubleshooting report.
