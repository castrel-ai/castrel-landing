## Full Release Checklist

### feat

- Optimized get_connector_info API with Skills metadata query support.
- Completed migration of remaining Connectors to the plugin architecture.

### bugfix

- Fixed integration plugin pages displaying incorrect language content.
- Fixed an issue where stopping a session during Proxy command execution showed a false "session running" error when sending new messages.
- Fixed an issue where stopping a session while Ask User Question or Write Document tools were active caused the page to remain in a loading state instead of correctly displaying the stopped status.
