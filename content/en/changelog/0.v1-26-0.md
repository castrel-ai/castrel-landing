## New Feature: Collaborative Incident Response

Team members can now investigate the same incident together while running multiple tasks in parallel. Every task shares the incident description, impact scope, and linked alerts, so each investigation can move forward with the same context.

Incident details bring the current status, findings, reports, and cleaned activity records into one place. Teams can add comments, track progress, and follow incident status based on the investigation tasks.

## 1 New Integration, 1 Enhanced Integration

- **New:** Infrastructure Monitoring, with infrastructure resource queries and support for Huawei switches.
- **Enhanced:** WeCom, with custom application URLs for private deployments.
