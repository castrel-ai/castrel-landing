## Full Release Checklist

### feat

- Dashboard now supports MCP connectors.
- Application CI get now correctly reads MCP tools from custom integration configurations.
- Sub-agents now support custom connector types via environment variable configuration, enabling MCP instance calls.
- Knowledge tags now display specific MCP instance names for easy differentiation.
- Root cause analysis reports now provide multiple candidate root causes for more efficient troubleshooting in complex scenarios.

### bugfix

- Fixed an issue where write_document tool call visualization charts were not rendered correctly.
- Fixed an issue where time series chart connecting lines broke across null data points.
- Fixed an SMTP certificate validation issue with email verification codes and workspace invitations.
- Fixed a GitHub integration configuration issue in domestic and UAT environments.
