## New Built-in Task

Operational knowledge often remains scattered across individual experience, leaving connected applications, services, and connectors without structured business semantics — purpose, ownership, dependencies, environment assignments, and more. This leaves AI agents with insufficient context during incident response. This release adds a built-in automation task called "System Knowledge Completion" to close this gap: it scans connected resources, identifies knowledge blind spots that slow down troubleshooting, and guides teams through structured questionnaires to fill them in. The completed knowledge is automatically linked to the corresponding resources so that every incident response starts with the right context.

## Full Release Checklist

### feat

- Dashboard now supports MCP connectors.
- Application CI get now correctly reads MCP tools from custom integration configurations.
- Sub-agents now support custom connector types via environment variable configuration, enabling MCP instance calls.
- Knowledge tags now display specific MCP instance names for easy differentiation.
- Root cause analysis reports now provide multiple candidate root causes for more efficient troubleshooting in complex scenarios.
- Added a system knowledge completion automation task that scans for knowledge gaps, generates structured questionnaires, and stores verified facts as long-term knowledge.

### bugfix

- Fixed an issue where write_document tool call visualization charts were not rendered correctly.
- Fixed an issue where time series chart connecting lines broke across null data points.
- Fixed an SMTP certificate validation issue with email verification codes and workspace invitations.
- Fixed a GitHub integration configuration issue in domestic and UAT environments.
