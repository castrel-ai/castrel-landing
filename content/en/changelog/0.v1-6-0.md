## New Feature: Domestic Pro Plan Launch

The focus of this commercialization phase is the official release of the Pro subscription plan tailored for the domestic market. The current version supports both monthly and annual subscription modes. Upon subscription, tenants can enjoy a fixed monthly point quota and invite up to 5 team members to collaborate, ensuring small and medium-sized teams have more stable computing power and quota guarantees in troubleshooting scenarios.

## Full Release Notes

### feat

* Launched the domestic Pro plan billing system, supporting monthly/annual subscriptions and collaboration for up to 5 members.
* Added SMS verification code login functionality, fully supporting mobile number registration and login for domestic users.
* Optimized the new user registration process by removing the strict dependency on initializing data connector configurations.

### bugfix

* Fixed an issue where messages sent from Feishu were not synchronized and displayed in real-time on the Castrel chat interface.
* Fixed a horizontal layout shift anomaly triggered by scrolling when mentioning services using `@` in the sub-agent configuration page.
* Fixed an issue where exporting or copying Markdown from documents in the chat would result in empty (undefined) content.
* Fixed the chat document version loading logic to ensure the sidebar automatically displays the latest edited version when re-entering historical sessions.
