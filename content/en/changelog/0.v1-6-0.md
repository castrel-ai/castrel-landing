Tuesday, April 14, 2026 · v1.6.0

This release focuses on domestic market commercialization, delivering a fully revamped registration experience, the first launch of a billing system, along with a series of experience improvements and bug fixes across chat document management, Feishu integration, and agent configuration.

---

## New Features

- **SMS Verification Code Login**: Users in China can now register and sign in using a mobile phone number with an SMS verification code — no GitHub or Google account required. This significantly lowers the barrier to entry for domestic users. First-time registrants are also prompted to provide a company name to help the platform better serve enterprise customers.

- **Domestic Pro Plan Billing**: We're officially launching a Professional subscription plan for the domestic market, available in both monthly and annual billing cycles. Subscribers receive a fixed monthly credit quota and can invite up to 5 team members, making it ideal for small and medium-sized teams.

- **Connector-Free Onboarding**: New users are no longer required to configure a data connector immediately after registration. Users can now explore Castrel's core features right away and connect external data sources whenever they're ready, delivering a much smoother first-time experience.

---

## Improvements

- **Chat Documents Always Show the Latest Version**: Improved the document version loading logic so that when users re-open a previous session, the document panel automatically loads and displays the most recently edited version — no more seeing stale content from earlier drafts.

---

## Fixes

- **Feishu Integration Message Sync**: Fixed an issue where messages sent from the Feishu side were not being displayed in the Castrel chat interface, even though Castrel had already started responding. Multi-turn conversation history initiated via Feishu is now rendered in real time and in full.

- **Agent Configuration Layout Shift**: Fixed a layout bug in the sub-agent Prompt System editor where using @ to mention a service caused the page to shift horizontally while scrolling. The configuration experience is now smooth and stable.

- **Document Export/Copy Returns Empty Content**: Fixed an issue where exporting or copying a document as Markdown from the chat interface resulted in empty (undefined) content. Document content is now correctly captured and exported in full.
