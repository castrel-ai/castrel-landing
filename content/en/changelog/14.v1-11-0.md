## Full Release Checklist

### feat

- Optimized Incident Studio to reuse the unified Graph and Chat framework, removing incomplete feature entries.
- Redesigned the Automation homepage with a new Tab Layout and removed the top input box.
- Added region-specific integration channel adaptation for the overseas site, displaying brand logos and locale-appropriate IM options.
- Added SaaS Enterprise user tier with configurable token quota and automation limits in Admin.
- Added batch application selection via multi-select checkboxes in the service list.
- Added application association option during integration data sync.
- Added a user prompt when chat conversation compression is triggered.
- Improved the automation creation and editing form layout.
- Adjusted Health Check mode visibility — hidden from homepage and creation page, locked on edit page.
- Added Skills implementations for 8 plugins: Tempo, Loki, ClickHouse, VictoriaMetrics, SkyWalking, Zabbix, K8s, and Grafana.

### bugfix

- Fixed SkyWalking integration compatibility with version 8.x.
- Fixed SkyWalking dependency sync producing dependencies not belonging to Service/Infra.
- Fixed inaccurate token counting when LLM API returns cached token metrics, causing premature compression and billing drift.
- Fixed an issue where the troubleshooting agent entered an infinite loop when no connector was provided.
- Fixed the Demo Connector quick-creation feature on the plugins page.
