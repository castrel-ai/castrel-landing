## New Feature: Evidence References That Hold Up Everywhere

When AI cites the result of a tool call — a metrics chart, a log query — as supporting evidence, that reference now looks and behaves the same wherever it shows up: in chat messages, expanded reports, and the side panel. Clicking it always surfaces the same content.

Evidence from a sub-task or an automated inspection session opens just as reliably, as long as you have access to that session, and takes you straight back to the original conversation for full context.

References in knowledge base articles, incident reports, and notifications pushed through IM channels like Feishu are also directly clickable, so you can verify the source behind any conclusion no matter where you run into it.

## Full Release Checklist

### feat

- Unified the display and interaction of tool-call evidence references across chat, reports, and the side panel.
- Aligned the app management dialog style with the personal access token page.
- Refactored alert detail components and data migration logic for improved stability.

### bugfix

- Fixed a permission error when integrating Feishu documents via QR code; required permissions are now configured automatically after the app is created.
- Fixed Feishu knowledge base queries returning an empty list; added knowledge spaces are now returned correctly.
- Removed a Feishu knowledge base node query tool with a parameter validation defect that caused errors.
- Fixed a missing save button on the "replace app link" configuration page in Feishu document integration, which prevented changes from taking effect.
- Fixed the download button remaining clickable while a chart was still loading; it's now disabled until loading completes.
- Fixed the topology graph not refreshing automatically after saving and exiting, requiring a manual refresh to see the latest topology.
- Fixed an occasional redirect to the new task page for regular users visiting app management.
- Fixed the download button not being disabled during document export, which could allow duplicate downloads.
