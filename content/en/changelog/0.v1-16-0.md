## 1 New Integration

- **New:** DOCP (host listing, operations overview summary, and CMDB relation type pagination; pipeline tools are hidden).

## Full Release Checklist

### feat

- Unified knowledge triggering into resource query tools, expanding automatically by scope and always active globally.
- Improved document and knowledge detail page interaction with a merged unified view.
- Moved mode switching into the bottom-left plus menu of the input box for a more focused flow.
- Added DOCP integration with host listing, operations overview, and CMDB relation queries.

### bugfix

- Fixed an issue where the app detail page only showed health scores from the last 2 inspections; full inspection history is now displayed.
