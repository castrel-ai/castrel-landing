## New Feature: Incident Task Management

Incidents now have a default management task. Teams can open it from the incident record to coordinate an investigation.

The task stays linked to the incident, making it easier to follow investigation work in one place. Read more in [Incident Investigation](/docs/features/incident-investigation).

## New Feature: Tool Calls Linked to Incident Activity

Incident findings can now link to the corresponding tool calls. Open an activity to review the related call record.

These links make the investigation easier to trace. Read more in [Incident Investigation](/docs/features/incident-investigation).
