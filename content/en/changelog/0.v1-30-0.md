## New Feature: Start Investigating from the Incident

Every incident now has a default management task. Responders can start investigating from the incident itself, without first creating a task and restating what happened.

When teammates investigate the cause, impact, and recovery in parallel, the management task keeps follow-up work tied to the same incident. Someone joining later can pick up from the findings already recorded there instead of repeating checks. Read more in [Incident Investigation](/docs/features/incident-investigation).

## New Feature: Verify the Evidence Behind Incident Findings

Incident findings can now link to the tool calls that produced them. When reviewing a finding, follow the link from the activity to its call record to check where the conclusion came from.

During handoffs and reviews, teams can see which findings have supporting evidence and which still need verification. Read more in [Incident Investigation](/docs/features/incident-investigation).
