## New Feature: Dashboard Generation and Execution Upgrade

You can now describe what you need in plain language and let the model generate dashboard query statements for you, so building a monitoring view no longer requires writing complex query syntax by hand.

Dashboards support grouping, letting you organize related dashboards by business line, environment, or team for easier navigation and maintenance. Charts within a dashboard support variable substitution, so the same dashboard template can be reused across different services or instances. Panel layouts can also be freely resized and repositioned by dragging, giving you control over information density.

A new dashboard execution tool is now available in conversations. From the knowledge module or general chat, you can trigger dashboard execution and view results directly, without switching to a separate dashboard page.

## 1 Enhanced Integration

- **Enhanced**: JumpServer (separates admin and user tokens, and lets regular users create jobs and correctly retrieve execution results)

## Full Release Checklist

### feat

- Added LLM-assisted dashboard query generation, with dashboard grouping, variable substitution, and drag-to-resize layouts.
- Improved JumpServer integration by separating admin and user tokens, and enabling regular users to create jobs and correctly retrieve execution results.

### bugfix

- Fixed a 422 authorization error that blocked Feishu Docs installation due to a missing configuration.
- Fixed an issue where marking an artifact as knowledge skipped name validation, causing existing knowledge with the same name to be overwritten.
- Fixed an issue where custom MCP calls incorrectly passed through the connection ID, causing tool calls to fail.
